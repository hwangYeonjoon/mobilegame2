# mobilegame2 안드로이드 생존 성장 게임

탕탕특공대의 한 손 생존 전투를 참고해, 짧은 전투와 장비·캐릭터 육성, 출석, NPC 상점, 보석 결제, 광고 보상으로 이어지는 Android 게임을 만든다.

**0.10.0 전투·현장 임무·전시 확장**: 첫 작전의 성장 간격과 첫 지역의 적 무리/정비 구간, 명중·처치·회수 효과음과 연속 처치 표시를 추가했다. 선택형 부품 회수·중계기 방어·수송 드론 호위, 개조 6종, 지역별 대형 시설물과 조명, 보상 등장 연출을 제공한다. 의상 기본 외형 비교·대원 확대 감상·사진 카드, 서버 검증에 따른 주간 길드 지원 활약 전시도 연결했다. 전투 규칙 버전은 **8**이며 이전 서버 작전은 계정 화면에서 종료 후 새로 출격해야 한다.

**0.9.0 전투 아트 개선**: 7개 지역의 바닥·시설물·지형을 분리하고 일반 적 6종, 지역 보스 7종을 새 아트로 교체했다. 이동·공격 준비·공격 자세, 피격 파편, 강화 탄환 궤적, 톱날·연쇄 전격, 보스 등장·위험 단계와 대원별 필살기 효과를 적용했다. 실제 장애물·위험 판정은 기존 42개 작전과 동일하며 경고선은 전투 효과 위에 표시한다. 전투 규칙 버전 7, 대원·아이템 가격·보상은 유지한다.

**0.8.0 첫 안내·의상 확장**: 초보 안내 5단계와 루크 전용 중장비 정비사 의상을 추가했다. 보석 600개 확정 구매, 이동·사격·필살기 자세, 전용 탄환·기어 충격파·지원 연출, 구매 전 드래그 체험, 공개 프로필·길드·주간 기록 반영을 제공한다. 전투 능력치는 변하지 않는다. [0.8 구현 문서](docs/13-outfit-and-onboarding.md).

**0.7.0 대원·지역 확장 프로토타입**: 대원 5명, 7지역 42작전, 도색 10종을 제공한다. 전격공 스파크와 냉각사 아이리스는 작전 12·24 완료 후 무료 모집하며 전용 패시브·필살기·길드 지원을 사용한다. 고압 발전소와 심층 용광로에는 새 지형과 보스·수집 보상을 추가했다. [0.7 구현 문서](docs/12-roster-and-regions.md)에 규칙·저장 이전·이미지 출처와 검증을 정리했다. 0.6의 개조 조합·전투 분석·길드 지원 등장·주간 기록 공유는 유지한다.

출격 화면에서 **특수 던전 · 코어 균열**과 **길드 · 지원 대원**으로 이동할 수 있다. 작전 05 완료 이후 90초 정식 도전과 전용 코어 파편 교환, 주간 기록판, 트로피 전시대를 이용한다. 길드에서는 동료의 대원을 하루 3회 빌려 일반 구역에서 호출할 수 있다. 자세한 규칙은 [0.4 구현 문서](docs/08-rift-guild-and-weekly-records.md)에 있다.

로컬 체험은 서버 없이 플레이할 수 있다. 별도로 실행한 서버에 연결하면 새 게스트 계정으로 시작하며, 출석·재화·장비·성장·전투 보상을 서버가 저장하고 확정한다. 로컬 재화는 서버에 가져오지 않는다.

실제 Google Play 결제·AdMob 광고·Google 로그인은 아직 연결하지 않았다. 상점의 현금 상품은 준비 중으로 표시하고, 로컬 체험의 설정 → 테스트 도구에서 체험 재화와 광고 스킵을 제공한다. 서버 계정에서는 테스트 지급을 차단한다. 현재 빌드는 스토어 배포본이 아니며 개발 빌드만 허용한다.

## 실행

- Unity `6000.3.7f1`로 이 폴더를 열고 `Assets/Scenes/Workshop.unity`에서 Play를 누른다. 씬의 카메라 외 UI와 전투 오브젝트는 실행 시 생성된다.
- Android APK: `Builds/Android/ScrapGuard-prototype.apk` — 0.10.0 개발 빌드(code 10). 서명·ARM64 라이브러리·16KB 정렬 검사 통과. 실기기 실행은 미검증.
- macOS 미리보기: `Builds/macOS/ScrapGuard.app`.
- 조작은 화면 드래그 또는 WASD·방향키. 공격은 자동이며 레벨업 때 스킬을 선택한다. 필살기는 충전 후 우측 하단 버튼 또는 Space. 빌린 길드 대원은 전투 시작 8초 후 지원 버튼 또는 Q로 호출한다. 일시정지는 우측 상단 또는 ESC.
- 빠른 검증은 설정 → 테스트 도구 → 45초 빠른 전투 테스트를 사용한다. 보스 처치에 걸리는 시간에 따라 종료 시각은 늘어난다.

## 서버 연결과 전시실

```sh
dotnet run --project Server/ScrapGuard.Server/ScrapGuard.Server.csproj
```

.NET 10 SDK가 필요하다. 기본 주소는 `http://127.0.0.1:5187`이며 DB는 서버 프로젝트의 `data/scrapguard.db`에 생긴다. 실행한 서버를 유지한 상태에서 게임의 **설정 → 계정·서버 연결**에 주소를 입력한다. 복구 코드를 비워 두면 새 계정을 만들고, 기존 개인 복구 코드를 입력하면 같은 서버의 계정으로 복구한다.

Android USB 테스트는 `adb reverse tcp:5187 tcp:5187` 실행 후 같은 루프백 주소를 입력한다. 다른 네트워크의 친구와 플레이하려면 별도의 HTTPS 서버 배포가 필요하다. 앱에 공개 운영 서버 주소가 포함되어 있지 않다.

**전시실 → 내 프로필 꾸미기**에서 닉네임·대표 대원·장비·칭호·외형을 고른다. 카드 공유는 Android 공유 창을 열고, macOS에서는 임시 캐시의 `showcase/`에 PNG를 저장한다. 공개 ID와 개인 복구 코드는 다른 값이다. 개인 복구 코드를 공유하면 계정에 접근할 수 있으므로 개인적으로 보관한다.

서버 전시 광장은 공개 동의한 같은 서버의 계정만 표시한다. 응원·신고·차단·차단 해제와 앱 내 계정 삭제를 제공한다. 랭킹이나 응원 수에 따른 재화 보상은 없다. 서버 실행의 기본 구조는 [0.2 구현 문서](docs/05-showcase-and-server.md), 최신 아트·필살기·베타 배포와 백업 절차는 [0.3 구현 문서](docs/06-art-combat-and-operations.md)에 정리했다.

## 빌드와 검증

```sh
dotnet run --project Tools/CoreChecks/CoreChecks.csproj
dotnet run --project Server/Checks/Checks.csproj
unity test . --mode EditMode --output TestResults/editmode.xml -- -nographics
unity run . -- -nographics -executeMethod ScrapGuard.Editor.ProjectBuilder.BuildMac
unity run . -- -nographics -buildTarget Android -executeMethod ScrapGuard.Editor.ProjectBuilder.BuildAndroid
```

`unity` 명령이 PATH에 없으면 `/Users/kd-server/.unity/bin/unity`를 사용한다. Android 빌드는 Android Build Support, SDK 36, NDK, OpenJDK가 필요하다. API 26 이상·ARM64 기기를 대상으로 한다. Android SDK 36은 target SDK이며 최소 설치 OS와 다르다.

Unity 메뉴에서도 **Scrap Guard → Build Android APK / Build macOS Preview**를 실행할 수 있다. `Configure Project`는 초기 씬과 Android 설정을 준비한다. 실수로 운영 빌드를 만들지 않도록 `PrototypeBuildGuard`가 Development가 아닌 빌드를 차단한다.

저장 위치는 `Application.persistentDataPath/scrap-guard-v1.json`이며 `.bak`에 직전 저장이 남는다. macOS에서는 일반적으로 `~/Library/Application Support/ScrapGuard/고철 수호대/`다. 테스트는 별도 임시 경로를 사용한다.

## 0.10 플레이 변화

첫 작전은 드롭을 일찍 모으지 못해도 약 8초에 톱날/코일/드론을 선택하고, 약 24초까지 두 번째 성장을 경험한다. 첫 지역에서는 22초 단위로 적 무리와 회수 구간을 번갈아 제공한다. 명중·처치·경험치·성장 소리는 동시 재생 빈도를 제한하고 설정의 효과음 끄기를 따른다. 연속 처치 표시는 2.5초 안에 이어진 처치의 연출이며 추가 재화 배율은 없다.

| 지역 내 작전 | 선택형 현장 임무 | 완료 조건과 보상 |
| --- | --- | --- |
| 2·5번째 | 부품 회수 | 장치 100 거리 안에서 안전/과부하 선택. 안전은 체력 12% 수리, 과부하는 20초 생존 중 화력·받는 피해 +20%와 적 증가 |
| 3번째 | 중계기 방어 | 105 거리 안에서 누적 18초 방어. 장치 65 거리 내 적이 내구도를 감소시킴 |
| 4번째 | 수송 드론 호위 | 105 거리 내에서 24초 호위. 65 거리 안에 적이 있거나 대원이 멀어지면 정지 |

현장 임무는 12~70초에 진행하며 실패하거나 무시해도 본 작전은 계속된다. 성공 후 **본 작전 승리 시** 골드 200·부품 2, 과부하 회수는 골드 400·부품 4를 기존 결과에 합산한다. 완료 시 경험치 6은 해당 전투에만 적용한다. 중단·패배에는 현장 재화 보너스가 없다. 주간 코어 균열에는 현장 임무를 넣지 않았다. 회수 선택은 리플레이에 기록하며 서버는 신고된 성공·보상 대신 동일 시뮬레이션으로 정산한다.

기존 개조 3종에 **파열 리벳**(리벳 탄막 3 + 고밀도 탄환 2, 기본 탄환 폭발), **수리 드론**(드론 3 + 응급 수리 2, 10초마다 체력 3% 수리/8% 보호막 보충), **냉각 자력장**(충격 코일 3 + 자력 수집 2, 범위 확대·둔화)을 추가했다. 실제 스킬 명칭은 게임 내 도감에 표시하며 개조는 전투 종료 시 초기화된다.

지역마다 새 대형 시설물을 하나 배치했다. `Campaign.Blocks`의 실제 충돌 영역과 발판을 공유하고 상부 구조물만 위로 돌출한다. 새 래스터 아트는 내장 imagegen으로 만든 `Assets/Resources/Art/Landmarks-v1.png`, 정확한 프롬프트는 `ArtSource/Landmarks-v1.prompt.txt`다. 기존 소형 시설물을 스타일 참조로 사용했다. 바닥 조명과 금속 그림자, 정지 프레임 사이의 이동 동작 유지, 보상 등장 연출도 보강했다.

전시실과 공개 프로필의 **확대 감상**에서 대기·이동·사격·필살기 동작, 방향 전환, 사진 카드 공유를 제공한다. 기본 대원의 동작은 위치·회전·스케일 연출이며 중장비 의상은 전용 자세 시트도 사용한다. 의상 체험의 **기본 외형과 비교**는 소유권·재화·전투 능력치를 바꾸지 않는다.

길드의 **이번 주 지원 활약**은 서버가 재생한 30초 이상 일반 전투에서 실제 지원을 호출한 경우만 집계한다. 사용 횟수·승리 횟수·도운 동료 수를 구분하고, 도운 동료 수 → 승리 수 → 안정적인 ID 순으로 활약 길드원을 전시한다. 집계는 길드원 단위이며 외형은 현재 등록한 대원을 보여 준다. 같은 동료를 반복 지원해도 도운 인원은 증가하지 않는다. 현재 같은 길드의 구성원과 차단 관계를 반영하며 새 주에는 빈 전시로 시작한다. 길드 내부 감상은 외부 사진 공유를 비활성화하고, 공개 프로필에서는 기존 공개 범위로 공유할 수 있다. 전시 순위에 재화 보상은 없다. 신규 DB 테이블 `support_runs`는 전투 정산과 같은 트랜잭션에 기록하고 요청 재시도에도 중복되지 않는다.
