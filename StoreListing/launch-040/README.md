# 실제 로봇 플레이 스크린샷

2026-11-24 Google Play에서 설치한 정식 0.40.0(code 43)의 실제 플레이를 캡처했다. 사용자 동의하에 격리된 라이선스 검증 계정으로 플레이했고 화면을 합성하거나 게임에 없는 요소를 넣지 않았다. 0.40.1(code 44)은 아이콘 변경이며 전투 규칙 30과 게임 화면은 같다.

- `01-robot-battle.png`: 로봇에 탑승한 실제 전투. Play 기본 스토어의 첫 휴대전화 스크린샷으로 제출했다.
- `02-robot-assembly.png`: 실제 로봇 설계 창. 참고용으로 보관하며 이번 첫 화면 교체 제출에는 사용하지 않았다.
- 두 파일 모두 원본 540×960. 기존 휴대전화 스크린샷 4장은 첫 화면 뒤에 유지했다.

새 설치·스토어 아이콘은 `Assets/Art/AppIcon.png`, `Store/ko-KR/icon-512.png`이며 생성 과정은 `ArtSource/app-icon-v2-prompt.md`에 기록했다.
