## 링크와 측정

`campaign-links.json`에 5개 고유 캠페인을 기록했다. Google Play URL의 직접 UTM과 URL 인코딩한 `referrer`가 같은 값을 가지는지 검사했다. 계정 ID·이메일·개인 식별자를 포함하지 않는다.

| 캠페인 | 설치 링크 위치 |
|---|---|
| `yt_gameplay_20261126` | 기존 가로 영상 설명 |
| `yt_channel_20261126` | 채널 프로필의 고철 수호대 링크 |
| `yt_short_transform_20261126` | 변신 Shorts 설명의 복사용 링크 |
| `yt_short_design_20261126` | 도감 Shorts 설명의 복사용 링크 |
| `yt_short_assemble_20261126` | 조립 Shorts 설명의 복사용 링크 |

Shorts 설명/댓글 URL은 클릭되지 않는다. 영상에는 채널 프로필 링크를 안내한다. 채널 프로필을 통해 설치한 사람은 **채널 공통 캠페인**으로 모이며 어느 Shorts를 봤는지 확정할 수 없다. 각 Shorts별 링크를 직접 연 경우만 해당 캠페인으로 구분할 수 있다. 관련 동영상으로 기존 가로 영상을 연결할 수 있다면 보조 이동 경로로 쓴다. 이 경로의 설치는 가로 영상 캠페인에 귀속되며 Shorts별 설치로 다시 합산하지 않는다.

앱에 Install Referrer SDK를 추가하거나 구매 개인정보를 수집하지 않았다. 현재 앱에서 캠페인별 구매 매출·광고 LTV까지 결합할 수 있다고 주장하지 않는다. 이번 작업은 Play의 UTM 스토어 유입 보고서로 범위를 한정한다.

### 게시 후 보고서 확인

1. YouTube Studio에서 영상별 유효 조회수, Shorts 피드 노출/시청 선택, 평균 시청 지속시간, 시청 유지율을 각각 기록한다. 일반 영상의 썸네일 CTR과 Shorts 피드 시청 선택률을 같은 지표로 취급하지 않는다.
2. Play Console → 사용자 늘리기 → 스토어 실적 → 전환 분석에서 소스를 `광고 및 추천`으로 선택하고 UTM 소스 `youtube`, 캠페인별로 나눈다. 방문자와 설치 버튼 클릭을 구분한다.
3. 2026년 보고서 변경으로 전환 분석의 설치 클릭은 **설치 완료가 아니다**. 실제 획득은 사용자 늘리기 개요/통계/다운로드 보고서에서 별도로 확인한다. 캠페인별 획득 CSV가 제공될 경우 그 수치를 사용한다.
4. 소량 데이터가 `기타`로 묶이거나 지연되면 0명으로 해석하지 않는다. YouTube와 Play의 날짜/시간대·집계 단위가 다르므로 숫자를 그대로 나눠 전환율을 만들지 않는다.
5. 게시 후 3일/7일 시점에 아래 빈 표를 채운다. 자동 보고서 수집이나 예약 알림을 설정한 상태는 아니다. 봇 조회·자기 반복 클릭으로 실험 수치를 채우지 않는다.
