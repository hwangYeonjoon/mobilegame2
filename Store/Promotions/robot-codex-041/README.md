# 로봇 도감 업데이트 홍보 초안

**2026-11-25 YouTube 공개 완료: https://youtu.be/5yfN0J4dO9Q.** 채널은 ‘이선생 게임공방’이다. Play 기본 스토어 영상과 앱 0.41.0(45)을 함께 검토 요청했다. Play 프로모션 초안에도 영상을 연결했으며 이벤트는 앱 공개에 맞춰 최종 제출할 예정이다. 커뮤니티 게시는 하지 않았다. 처음 검토했던 폭풍 구조대 소개보다 실제 추가한 도감·조립 목표 기능을 앞세운다. [등록 현황과 이어서 할 일](../../../docs/30-release-041-and-promotion.md).

| 자료 | 용도 |
|---|---|
| `play-promotion-draft.json` | 한국어 태그라인·설명·종류·초안 일정·공개 영상 URL |
| `primary-1920x1080.jpg` | 16:9 전용 홍보 일러스트. 1 MB 미만 |
| `square-1080x1080.jpg` | 정사각 홍보 일러스트 |
| `community-post-ko.txt` | 개발자임을 밝히는 외부 게시글 초안 |
| `gameplay-portrait.mp4` | 실제 Android 플레이 20초, 원본 540×960 |
| `gameplay-landscape.mp4` | 동일 영상의 1920×1080 가로판, 주변은 같은 영상의 흐린 배경 |
| `video-ko.srt` | 별도 한국어 자막. 영상에 문구를 구워 넣지 않음 |
| `edit-manifest.json` | 원본·결과 해시, 컷 시점, 패키지와 촬영 빌드 출처 |

그림은 실제 구조대 로봇 디자인을 참고한 **홍보 일러스트**이며 게임 스크린샷이 아니다. 앱 제목·문구·버튼은 넣지 않았다. 기존 스토어 feature graphic과 구별되는 조립 장면이다. 프롬프트와 출처는 `ArtSource/Promotion041-prompts.txt`에 기록했다.

## 실제 플레이 영상

출시 후보 0.41.0(45)의 정식 패키지를 Android QA 에뮬레이터에 설치하고 운영 서버에 연결해 촬영했다. 전투 중 포신 4개를 실제로 회수해 연사 포격 전차 특화형을 제작·탑승했다. 이후 1분 43초, 443마리 처치에서 직접 작전을 종료했고 서버가 골드 415·부품 3 정산을 수락했다. 승리 영상이나 QA 결과 화면이 아니다. 테스트 계정이며 실제 구매는 하지 않았다.

편집은 컷 연결만 했고 재생 속도는 바꾸지 않았다. 30fps 파일은 원본 프레임을 반복하므로 실기기 성능 증거로 쓰지 않는다. 배경음은 기존 게임의 CC0 `Overdrive`를 편집해 넣었으며 기기에서 녹음한 소리가 아니다. 라이선스는 `ArtSource/Audio/LICENSES.md`에 있다. 촬영 후 운반 적만 있는 획득처 안내와 전체 작전 완료 홈 버튼을 수정한 최종 빌드를 만들었다. 영상에는 해당 두 화면이 나오지 않는다. 촬영 APK와 최종 APK의 해시를 혼동하지 않는다.

원본은 용량과 테스트 보관 범위를 고려해 로컬 `TestResults/Promotion041/`에만 둔다. 해당 원본이 있으면 `python3 Tools/prepare_robot_promo.py`로 재편집할 수 있다. 완성 영상과 일러스트는 저장소에 포함했다. **가로판만 YouTube에 공개**했고 세로판은 업로드하지 않았다.

## 등록안

유형은 주요 업데이트의 새 기능(`MAJOR_UPDATE / FEATURES_&_ANNOUNCEMENTS`), 한국·한국어, 별도 할인이나 기간 한정 보상 없음. 프로모션 노출 기간이 끝나도 도감은 유지된다. 콘솔 초안은 2026-11-30 10:07 KST부터 12-28 10:07 KST까지 28일이며 사전 미리보기는 껐다. **앱 공개가 늦어지면 시작일을 조정한 뒤 제출**한다. 일반 검토에는 최소 4일, 추천 노출 요청에는 최소 14일의 여유가 필요하다. 추천 노출은 요청하지 않았으며 노출을 보장하지 않는다. [Google 등록 안내](https://support.google.com/googleplay/android-developer/answer/12932541?hl=en).

1920×1080 가로 그림과 별도 정사각 그림을 준비했다. 가로 그림의 주요 로봇은 중앙에 배치했다. 최종 콘솔 미리보기에서 잘림을 다시 확인한다. 가로판 영상은 YouTube 공개·임베드 허용으로 업로드해 URL을 연결했다. 영상 수익화는 활성화하지 않았으나 플랫폼의 모든 광고 미노출까지 보장하지 않는다. [Google 콘텐츠 품질 안내](https://support.google.com/googleplay/android-developer/answer/12929944?hl=en).

## 게시 뒤 확인할 것

같은 기간 신규 유입을 기준으로 Play 스토어 방문→설치, 첫 작전 완료, 첫 특화형 탑승, 다음 날 재방문을 함께 본다. 설치만 늘고 첫 탑승이 줄면 홍보 확대보다 동선부터 확인한다. 첫 7일은 표본 수와 함께 실제 건수를 기록하고, 적은 표본으로 전환율 개선을 단정하지 않는다.

Play 획득 보고서와 동의한 게임 플레이 기록은 서로 다른 자료다. 이번 클라이언트의 도감 목표 기록은 로컬 연구 기록이므로 자동 서버 KPI나 사용자별 광고 기여도로 표시하지 않는다. 외부 글은 채널별로 게시일·링크·노출·클릭을 적되, 측정 연결이 없는 설치를 해당 글의 성과로 단정하지 않는다.

관찰 질문: 강화 메뉴를 스스로 찾았는가, 목표 로봇을 골랐는가, 필요한 부품을 어디서 모으는지 설명할 수 있는가, 실제 탑승까지 이어졌는가. 테스터에게 특정 로봇을 먼저 고르라고 유도하지 않는다.
