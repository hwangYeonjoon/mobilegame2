개인정보처리방침

MrStudio는 Android 게임 고철 수호대(io.github.hwangyeonjoon.scrapguard)의 계정, 저장, 구매 확인, 광고 보상 및 고객지원을 위해 아래 정보를 처리합니다. 로컬 체험과 서버 계정은 별도로 저장됩니다.

1. 처리하는 정보와 목적

구분정보와 이용 목적
서버 계정무작위 공개 ID, 복구 코드의 해시, 생성 시각, 게임 진행·재화·장비·거래 기록: 계정 인증, 저장·복구, 보상 지급 및 부정 이용 방지
Google 계정 연결

게임 운영 통계보석 획득·소비, 의상 구매·장착, 활동 날짜: 게임 경제와 서비스 운영. 미보유 의상 체험 기록은 앱에서 별도 동의한 경우에만 수집합니다.
접속·문의IP 주소는 요청 제한과 보안에 사용합니다. 오류 진단 로그, 문의 이메일 주소·내용·첨부자료는 장애 대응과 고객지원에 사용합니다.

2. 선택과 거부

Google 연결, 보상형 광고 시청, 의상 체험 통계는 선택 사항입니다. 체험 통계는 앱 설정에서 철회할 수 있으며 철회 시 해당 체험 기록을 삭제합니다. 광고 개인정보 선택은 앱 설정의 광고 개인정보 메뉴가 제공되는 지역에서 변경할 수 있습니다. 선택 항목을 거부해도 해당 기능을 제외한 게임 이용은 가능합니다.

3. 처리 위탁 및 외부 서비스

게임 서버와 DB는 Amazon Web Services(AWS)의 대한민국 서울 리전 Lightsail에 보관합니다. Cloudflare는 도메인·DNS를 제공하며 현재 게임 API는 DNS only 방식으로 운영합니다. Google 로그인·Google Play 결제·Google AdMob 광고는 Google의 서비스와 연결되며, 해당 기능 이용 시 필요한 식별 정보가 Google에 전송됩니다. Google은 미국 등 해외에서 정보를 처리할 수 있습니다.

4. 보관 기간과 삭제

  • 계정과 게임 진행·Google 연결·소셜·개인별 게임 통계는 계정 삭제 시 운영 DB에서 삭제합니다.
  • 선택 의상 체험 및 활동 일자 기록은 최대 90일 보관합니다. 계정 삭제 시 함께 삭제합니다.
  • 계정 삭제 후에도 이미 처리한 구매 토큰의 해시와 계정 연결이 제거된 상품·지급·환불 상태는 중복 지급·환불 악용 방지를 위해 서비스 운영 기간 동안 보관합니다. 원본 구매 토큰의 암호화 값은 계정 삭제 시 제거합니다. 이를 완전한 익명 정보로 간주하지 않습니다.
  • 서버 백업은 최대 30일 순환 보관하고 만료 시 삭제합니다. 백업에 남은 정보는 장애 복구 목적으로만 제한적으로 보관하며 만료 시 삭제합니다.
  • 고객지원 이메일은 문의 종료 후 최대 3년간 보관하며, 법적 의무로 별도 보관이 필요한 경우에는 해당 사유와 기간을 안내합니다. 서버 진단 로그는 파일 크기 제한에 따라 순환합니다.
