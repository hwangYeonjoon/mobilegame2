# 0.7 대원·작전 확장

2026-11-03. 앱 0.7.0(code 7), 전투 규칙 7. 대원 5명, 7지역 42작전, 도색 10종. 0.6의 개조 3종·전투 분석·길드 지원·주간 기록은 유지한다.

해금은 서버에 저장된 해당 작전의 실제 클리어 기록으로 검사한다. 표시된 최고 해금 작전 번호만으로 모집할 수 없다. 재화 비용과 중복 지급은 없으며 보석 상점에 신규 대원을 추가하지 않았다. 기존 구매 대원과 출석 대원의 조건은 그대로다.

냉각 효과는 코어 균열의 고정 코어에 적용되지 않는다. 빙결 중 새 행동·이동은 멈추지만 이미 예고된 공격을 취소하지는 않는다. 두 새 대원 모두 기존 장비·강화·개조·필살기 충전·전시·피팅룸·길드 지원에 연결했다. 도색은 능력치를 바꾸지 않는다.

기본 공격/체력 계산을 `Catalog.AttackFor`, `HealthFor`로 통일했다. 전시실·출격·지원이 서로 다른 계산식으로 소수점 경계에서 1씩 다르게 표시되던 경우를 방지한다.

## 새 지역과 작전

| 지역 | 작전 | 지형 | 보스 |
| --- | --- | --- | --- |

33·35·39·41은 생존 목표, 나머지는 보스 토벌 목표다. 일반 적은 기존 6역할의 지역별 조합을 사용한다. 새로운 일반 적 역할을 추가한 것은 아니다. 새 지형은 기존 UI 기반 맵 렌더러로 제작했으며 새로운 배경 PNG를 사용하지 않는다.

각 작전 최초 완료에는 기존과 같은 보석 50개와 지정 장비를 제공한다. 추가 12작전의 최초 무료 보석은 합계 600개다. 성공 골드·부품은 기존 작전별 수식을 따른다. 지역 설계도는 성공 1개, 마지막 작전 36·42 성공은 2개이며 실패·중단에는 없다.

지역 설계도 8개로 **번개의 황금빛**, **용광로의 홍옥빛**을 각각 확정 제작한다. 기존 8종과 합쳐 도색 10종이며, 두 신규 보스도 도감에 기록된다. 제작·착용·공개 프로필·길드 지원 외형까지 연결했다.

## 이전 저장과 운영 호환

- 기존 대원 ID 0~2, 지역 ID 0~4, 작전 ID 0~29, 도색 ID 0~7을 유지했다. 새 콘텐츠는 뒤에 추가한다.
- 대원 3명으로 저장된 로컬 파일과 서버 계정은 새 슬롯 2개를 잠긴 상태로 추가한다. 기존 레벨·선택·소유권·재화는 유지한다. 12/24작전을 이미 완료했다면 바로 무료 모집할 수 있다.
- 30작전을 순서대로 완료한 계정은 31작전으로 이어진다. 신규 지역 설계도는 과거 플레이로 소급 지급하지 않는다. 기존 최초 보상을 다시 지급하지 않는다.
- 이전 규칙으로 시작한 서버 전투는 취소 후 다시 출격해야 한다. 앱과 서버를 함께 업데이트한다. 주간 순위 비교는 규칙 7 기록만 대상으로 하며, 이미 수령한 달성 보상은 초기화하지 않는다. 운영 업데이트는 주간 경계에 맞추는 것이 좋다.
- 실제 Google 로그인·Play 결제·AdMob은 이번에도 연결하지 않았다. 새 대원은 플레이 해금이다.

## 다음 콘텐츠를 추가하는 위치

- `Assets/Game/Core/HeroCatalog.cs`: 이름·기본 능력·해금 작전·필살기와 지원 설명. 대원 목록과 전시·피팅·지원 UI는 이 개수를 사용한다. 새 패시브·필살기의 실제 동작과 아트는 별도 구현해야 한다.
- `Assets/Game/Core/Campaign.cs`: 작전 이름·목표·적 구성·보상·지형. 마지막 작전 보상과 도감은 `FinalStage`로 찾는다. 기존 ID 사이에 삽입하거나 순서를 바꾸지 않는다.
- `Combat.Campaign.cs`, `BattleArt.cs`: 새 지형의 실제 판정과 화면 표현. 지역 이름만 추가해서 새로운 지형 동작이 생기는 구조는 아니다.
- `Social.Skins`, `CharacterArt`: 지역 도색과 색상, 신규 대원 atlas. 지역 도색 ID는 `3 + 지역 ID`다.
- 공통 규칙은 앱과 서버에 함께 포함된다. 무한 작전 생성·운영 중 원격 콘텐츠 배포·콘텐츠 편집기는 아직 구현하지 않았다.
