# 0.8 — 첫 플레이 안내와 루크 전용 의상

## 적용 범위

기존 5명·7지역 42작전·도색 10종을 유지하고, 독립된 의상 1종과 첫 플레이 안내를 추가한다. 도색의 지역 ID를 의상에 재사용하지 않는다. 실제 Google 결제·광고 SDK는 이번 작업 범위에 포함하지 않으며 여전히 미연결이다.

## 중장비 정비사

- 루크 전용. `outfit_heavy_engineer`를 보석 600개로 확정 구매한다. 가격은 프로토타입 밸런스 값이다.
- 중장갑, 리벳 대포, 크레인으로 기본 도색과 다른 실루엣을 제공한다. 대기·이동·사격·필살기 4자세를 사용한다.
- 구리빛 탄환과 포구, 기어 충격파, 길드 지원 등장 연출을 추가한다. 공격력·체력·피격 범위·스킬 판정은 변하지 않는다.
- 구매 후 별도 장착한다. `selectedOutfit=1`이어도 보유권이 없거나 대원이 루크가 아니면 적용하지 않는다. 해제해도 보유권과 기존 도색 선택은 보존한다.
- 상점의 스타일 탭에서 의상실을 연다. 체험 영역을 드래그해 이동하고 사격·필살기·지원 등장 버튼으로 연출을 확인한다. 체험은 `GameState`, `Economy`, 네트워크, 리플레이에 접근하지 않는 별도 컴포넌트다. 출격 티켓, 재화, 점수, 보상은 발생하지 않는다.
- 루크의 정비소·대원 목록·전투·전시실·공개 프로필·길드 지원·주간 기록에 적용한다. 주간 기록은 최고 기록을 낸 출격 당시 의상을 보관한다. 비공개 지원 대원의 의상은 수신자에게 보내지 않는다.
- 이동 자세는 정지/보행 프레임 교대, 사격/필살기는 해당 이벤트의 프레임 전환이다. 뼈대 애니메이션이나 3D 모델은 아니다.

## 첫 플레이 안내

정비소의 `초보 안내`에서 언제든 열 수 있으며, 처음 들어오는 계정에는 안내를 표시한다. 안내를 닫아도 다른 메뉴를 자유롭게 이용할 수 있다.

1. 실제 이동 거리 120 이상: 화면 드래그와 자동 공격 안내.
2. 실제 필살기 1회 사용: 처치로 충전하고 버튼으로 발동.
3. 성공한 첫 장비 강화: 장착 무기 관리로 연결.
4. 첫 개조 완성: 조합 도감으로 연결. 예시는 리벳 탄막 Lv.3 + 신속 장전 Lv.2.
5. 작전 6 클리어: 첫 지역 정복과 다음 지역 지도 연결.

전투 중에는 작전 1에 상황별 안내 문구를 표시한다. 전투 관련 진척은 정상 정산한 시뮬레이션에서만 저장하며, 서버 계정은 서버가 재생한 리플레이를 사용한다. 단순 안내 열기나 클라이언트의 승리·처치 수 신고로 달성할 수 없다. 강화 실패와 경계에 막힌 이동 입력은 진척으로 인정하지 않는다. 안내에는 별도 재화 보상을 붙이지 않았다.

기존 계정은 저장 내용을 유지한다. 이전 전투 경험이 있는 계정에 첫 안내를 강제로 띄우지 않고, 장비 레벨과 기존 개조 보고서로 확인 가능한 단계만 이전한다. 과거 이동·필살기를 확인 없이 달성 처리하지 않는다.

## 데이터와 서버

- `GameState`: `selectedOutfit`, `guideVersion`, `guideIntroSeen`, `guideMoved`, `guideUltimate`, `guideUpgrade`, `guideMod`.
- 명령: 기존 `cosmetic_buy`에 상품 추가, `outfit_equip`의 `skin` 필드에 의상 ID 0/1 사용, `guide_seen`은 안내 열람만 기록.
- `PublicProfile`, `GuildMember`, `SupportSnapshot`, `RankEntry`: `outfit` 필드. 이전 데이터는 0으로 해석한다.
- `weekly_records.outfit INTEGER NOT NULL DEFAULT 0`를 기존 점수를 삭제하지 않고 추가한다. 초기화 재실행도 안전하다.
- 구매·보석 차감·명령 재시도는 기존 서버 트랜잭션과 원장을 사용한다.
- 게임 버전 0.8.0 / Android versionCode 8. 판정 변화가 없으므로 전투 규칙 버전은 7을 유지한다.
