# 0.3 시점의 콘텐츠와 자랑·성장 확장안

이 문서는 0.3 시점의 설계 기록이다. 이후 0.4에서 코어 균열·주간 기록·전용 파편 교환·트로피 전시·길드 지원을 추가했다. 최신 구현은 [0.4 문서](08-rift-guild-and-weekly-records.md)를 따른다.

2026-11-02의 0.3 코드 기준. 아래에서 **현재 구현**과 **다음 제안**을 구분한다. 랭킹·시즌·무한 도전·방문형 전시실은 아직 구현하지 않았다.

## 현재 구현

| 영역 | 현재 범위 |
| --- | --- |
| 구역 | 1 버려진 정비소 / 2 철길의 불청객 / 3 폐기물 처리장 / 4 멈춰버린 공장 / 5 중앙 제어 코어 |
| 길이 | 첫 1탄은 3분 기준, 이후 5~6분 기준. 보스를 빨리 처치하면 종료가 앞당겨지고 늦으면 연장된다. 설정의 45초 전투는 테스트 전용 |
| 캐릭터 | 루크 기본 / 레이 보석 1,200 / 볼트 누적 출석 7일. 각기 기본 능력·특성과 필살기가 다름 |
| 성장 상한 | 캐릭터 Lv.30, 장비 Lv.20. 장비 12종: 무기 6 / 갑옷 3 / 모듈 3 |
| 최초 클리어 | 구역당 보석 50, 총 250. 장비 1개도 지급, 보관함이 차면 부품 30개로 대체 |
| 반복 전투 | 클리어 골드 1,500~2,500, 부품 10~18. 실패/중단도 생존 시간에 따른 제한 보상. 반복 횟수 자체 제한 없음 |
| 출석 | 7일 주기 반복. 골드 1,000 → 부품 20 → 보석 50 → 골드 2,000 → 부품 40 → 보석 100 → 볼트. 볼트 보유 이후 7일차는 부품 60 |
| 일일 임무 | 30초 이상 전투 3회와 처치 500을 달성하면 골드 2,000 + 부품 20 + 보석 30, 하루 1회. 한국 시간 오전 5시 초기화 |
| 전시 | 대표 대원·장비 3개·도색·칭호·프레임, PNG 카드 공유, 서버 광장·응원·신고·차단 |
| 무료 외형 | 첫 클리어 칭호/프레임, 7일 출석 칭호/프레임, 1,000처치 칭호/서리 도색, 5개 구역 클리어 칭호 |

출석과 반복 보상에 마지막 날짜는 없다. 그러나 새 구역은 5탄에서 끝나며 이후는 같은 구역 반복과 성장 상한까지의 수집이다. 현재 콘텐츠만으로 몇 달간 과금 동기를 유지한다고 볼 수 없다. 실제 플레이 시간과 성장 속도도 아직 측정하지 않았다.

## 상점에서 지금 할 수 있는 것

| 상품 | 가격/한도 |
| --- | --- |
| 일반 장비 9종 | 개당 골드 3,000, 합계 하루 2개 |
| 희귀 충격 발사기 1종 | 보석 600, 영구 1회 |
| 부품 20 | 골드 2,000, 하루 1회 |
| 부품 100 | 보석 100, 하루 1회 |
| 레이 해금 | 대원 화면, 보석 1,200, 영구 |
| 앰버 도색 | 보석 300, 세 대원 공용, 능력치 변화 없음 |
| 태양 프레임 | 보석 250, 전시용 |

장비 화면에서 미장착·미잠금·Lv.1 장비를 판매할 수 있다. 일반/고급/희귀 매입가는 골드 300/600/1,200이다. 강화 장비는 먼저 강화 이전이 필요하다. 유저 간 거래는 없다.

## Google 결제의 현재 상태

**실제 결제로 얻을 수 있는 상품은 현재 0개다.** Google Play Billing/Play Console 상품/서버 구매 검증/복원·환불은 아직 연결하지 않았다. 화면의 금액은 제안 가격이며 결제가 실행되지 않는다. 제안 SKU는 다음 4개다.

| 상품 | 제안 가격 | 지급/권리 |
| --- | --- | --- |
| gems_100 | 1,500원 | 보석 100 |
| gems_450 | 5,900원 | 보석 450 |
| gems_1000 | 12,000원 | 보석 1,000 |
| ad_skip_lifetime | 9,900원 | 같은 일일 한도 내 보상형 광고 시청 생략 |

충전한 보석으로 캐릭터·희귀 장비·부품·외형을 구매하는 구조다. 실제 가격은 Play가 제공한 지역 가격을 표시해야 한다. 광고 스킵은 결과 추가 골드 하루 3회, 부품 하루 2회의 시청을 생략하는 영구 권리로 계획했다. 현재 실제 광고도 없으며 로컬 테스트 체험만 있다. [Google Play 결제 정책](https://support.google.com/googleplay/android-developer/answer/9858738?hl=en).

출시 전 상품 단가를 검토하고, 레이 1,200보석 해금에 맞는 수량 구성도 검토한다. 현재 제안 금액을 그대로 등록하지 않는다. 또한 유료/무료 보석 원장 분리, 구매 토큰 중복 검증·환불·권리 복원, 게스트 계정의 Google 연동을 먼저 구현한다.

## 게임 정체성과 시작 화면

한 문장: **버려진 고철로, 나만의 수호대를.**

첫 화면은 세 대원과 고철 공장의 색상, 생존·성장·전시라는 세 가지 목적을 보여준다. 엔진 로고 표시를 비활성화하고 ‘정비소로 들어가기’로 바로 진입한다. 가짜 로딩이나 강제 대기 시간은 두지 않는다. Android OS가 자체적으로 표시하는 앱 아이콘 시작 화면과 게임 타이틀은 별개이므로 Android 실기기에서 함께 확인해야 한다. [Unity SplashScreen.show API](https://docs.unity.com/en-us/engine/6000.3/script-reference/unityeditor/playersettings/splashscreen/show).

## 추천 확장 구조 — 아직 미구현

자랑하려면 장식뿐 아니라 **누가, 어디에서, 얼마나 자주 보는지**가 있어야 한다. 구매 → 내 화면에서만 감상으로 끝나면 외형의 가치가 약해진다. 다음 구조를 제안한다.

| 축 | 보여줄 성과 | 타인에게 노출되는 곳 | 보상/판매 연결 |
| --- | --- | --- | --- |
| 성장 기록 | 성장 장비로 도전한 최고 층수·주간 보스 점수 | 주간 기록판, 프로필 최고 기록, 친구 비교 | 성장 투자 성과. 순위 보상은 트로피·칭호 중심 |
| 실력 기록 | 동일 대원·장비·시드로 제한된 도전 기록 | 별도 실력전 기록판과 시즌 배지 | 돈으로 살 수 없는 숙련 증명, 외형만 적용 |
| 수집·취향 | 도색 세트, 캐릭터, 전시대와 배경 | 방문형 정비소, 광장 카드, 공유 카드 | 확정 스킨 세트·승리 포즈·전시 배경 판매 |
| 협동 기여 | 주간 길드 공동 목표 참여/보스 기여 | 길드 로비·공동 보스 종료 화면 | 길드 트로피, 공동 목표 해금, 기여 칭호 |

전투력 숫자 정렬만으로 전체 랭킹을 만들면 오래 성장한 계정과 신규 계정의 차이가 크고 반복 노출도 제한된다. 성장 모드의 실제 보스/층 기록으로 경쟁하고, 주간 기준과 비슷한 진행 구간끼리의 비교를 둔다. 별도 실력전은 서버가 대원·장비 스냅샷을 고정하고 기록을 재현해야 한다. 성장 순위에 높은 재화 보상을 주어 상위가 계속 독식하기보다, 참여/개인 기록 달성에 기본 재화를 주고 순위에는 명예 외형을 준다.

단순히 구매한 희귀 외형과 실제 업적 배지는 표시를 구분한다. 스킨은 누구나 미리 볼 수 있는 확정 구성으로 판매하고, 시즌 최고 층·무피격 보스·초기 시즌 참여 같은 트로피는 실제 조건 달성으로만 얻는다. 두 종류를 함께 전시하면 취향과 성취를 모두 보여줄 수 있다. 판매한 외형에 나중에 전투 능력치를 붙이지 않는다.

광장은 인기 수만으로 고정 정렬하지 않고 신규 공개 전시실과 최근 바뀐 전시실에도 노출 기회를 준다. 방문·응원은 하루 중복 집계와 자기 응원을 제한하며, 응원 수에 재화 보상을 걸지 않는다. 차단·비공개·계정 삭제가 노출과 기록 조회에도 적용되어야 한다.

## 콘텐츠와 상품 우선순위

1. **5탄 이후 주간 코어 도전 + 개인 최고 기록.** 주간 참가 보상/단계별 달성 보상/최고 기록 트로피를 먼저 만든다. 기존 성장의 사용처가 생긴다. 처음부터 50개 비슷한 탄을 늘리지 않는다.
2. **방문형 전시실.** 대표 대원, 장비 3개, 업적 트로피 3칸, 배경 1개. 게임 결과와 광장 카드에서 한 번 눌러 방문한다. 실제 이용자 방문은 자동 알림/메시지 전송 없이 게임 안의 카운터로 보여준다.
3. **주간 성장 기록판.** 검증된 서버 기록만 등록, 동점 규칙 고정, 주간 마감 스냅샷, 보상 중복 방지, 차단/비공개 필터 포함. 랭킹 화면의 상위 이용자에서 전시실로 이동한다. 로컬/테스트 계정은 제외한다.
4. **외형 세트와 승리 포즈.** 도색+필살기 색상+전시 배경을 세트로 미리보기. 공격 범위·판정·피해는 바꾸지 않는다. 정확한 가격은 콘텐츠 가치와 실제 이용 데이터를 본 후 결정한다.
5. **Google 계정·실제 결제/광고 검증**, 이어 동일 조건 실력전과 길드 기여. 시즌패스는 최소 한 시즌분의 확정 콘텐츠와 보상표를 제작한 뒤 검토한다.

사업 가설은 ‘성장 투자 → 도전에서 성과 → 기록/전시 방문 → 다음 성장 또는 외형 구매’다. 아직 검증된 전환율은 없다. 5탄 클리어 후 재방문, 도전 참여/재도전, 타인 전시실 방문, 미리보기 후 관심 상품, 무료/구매 이용자의 진행 차이를 측정해 다음 콘텐츠를 결정한다. 어린이 대상 전환은 별도 제품 결정이며 지금 설계에서 어린이 결제를 유도하는 방향은 채택하지 않는다.
