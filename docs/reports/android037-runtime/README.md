- Apple M1 호스트 GPU에서 밀집 구간 평균 54.7~57.7 FPS, p95 16.7ms였다. p99 33.3~66.7ms 지연은 남으므로 60 FPS 고정이라고 하지 않는다. 실물 Android 폰의 성능 합격으로 사용하지 않는다.
- 소프트웨어 GLES에서는 밀집 구간 평균 11.5~15.5 FPS였다. Mac QA 기본값을 host로 바꾸고 swiftshader 선택지를 유지한다. Android 게임의 그래픽 API나 난이도를 바꾼 결과가 아니다.
- 보통/밀집 모두 체력 보정된 부하 fixture다. 밀집은 스킬 3레벨과 적 보충을 사용한다. 벽시계 기준 구간이므로 느린 환경은 전투 시간도 적게 진행한다. 동일 프레임 입력을 재생한 엄밀한 GPU 벤치마크가 아니다.
- CPU 비교 측정은 소프트웨어 방식 초반에 잠시 겹친 뒤 중지했고, host 방식 초반에 완료됐다. 두 방식의 밀집 구간에는 별도 Unity 빌드·코어 대량 측정을 실행하지 않았다. 에뮬레이터·호스트 환경 차이가 있어 실제 폰 발열·터치를 대체할 수 없다.
- adb 3시점 수집에서 두 방식 모두 앱 실행 상태를 확인했다. PSS는 소프트웨어 약 311~325 MiB, host 약 285~302 MiB였다. host의 일부 메모리는 swap에 있어 두 값의 차이를 게임 메모리 최적화로 해석하지 않는다.
- Android IL2CPP에서 만든 보스 연습·주간·극한 입력 15개를 .NET 코어로 재생했다. 개별 결과는 replay-check.json에 있다. 밀집 fixture는 해당 재생 표본이나 승률 표본에 포함하지 않는다.
- 시작 화면·첫 출격은 기존 수동 체험 APK에서도 직접 확인했다. 자동 QA는 보급 확인→구매와 강화→재출격 능력치 적용, 외형 팩, 무료 현장 보급, 보스 연습·주간·극한 화면을 검사했다. 서버 지연·재전송·실제 Google 결제·환불을 Android에서 이번에 검사한 것은 아니다.
