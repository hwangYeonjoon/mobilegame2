# 0.6 개조·전투 분석·지역 수집·지원 전시

## 이번 구현

0.5의 30작전을 유지하면서 비교 검토에서 제안한 다섯 가지를 구현했다. 실제 Google 결제·광고 SDK는 계속 미연결이다.

### 전투 중 개조 조합

| 개조 | 필요 스킬 | 실제 동작 |
| --- | --- | --- |
| 자력 분쇄기 | 회전 톱날 Lv.3 + 자력 수집 Lv.2 | 150 범위의 일반 적을 끌어당긴다. 보스·코어는 끌어당기지 않는다. 자력 범위 표시와 기존 톱날 공격을 함께 사용 |
| 연쇄 전격 드론 | 충격 코일 Lv.3 + 지원 드론 Lv.2 | 코일 공격이 드론에서 시작하는 전격으로 바뀐다. 최대 4개 서로 다른 적으로 연결, 다음 적까지 200 범위 |
| 회전 리벳 포탑 | 리벳 탄막 Lv.3 + 신속 장전 Lv.2 | 별도 포탑이 플레이어 주위를 돌며 0.28초 간격의 관통탄을 발사 |

조건 충족 시 자동 개조, 세 가지 동시 보유 가능, 전투가 끝나면 초기화. 기존 스킬 성장과 필살기는 유지한다. 스킬 선택 카드에 조합 진행도를 표시하고, 정비소의 **개조·수집 → 개조 조합 도감**에서 조건을 미리 확인한다. 전투 입력을 서버가 재현하므로 클라이언트가 개조 소유나 결과를 제출해 보상을 만드는 방식이 아니다.

### 전투 분석

일반전·균열 결과 화면의 **전투 분석**에서 종료 원인, 받은 체력 피해의 원인별 합계, 보스 잔여 체력, 보유 스킬과 완성 개조를 확인한다. 접촉·돌진·포격·자폭·오염·철로·레이저·보스 공격을 구분한다. 보호막 흡수와 초과 피해를 제외한 실제 체력 손실을 누적한다. 중단과 시간 초과도 사망과 구분한다.

대응 팁은 실제 종료 원인, 성공 시에는 가장 큰 피해 원인을 기준으로 한 가지 표시한다. 보스 미등장/생존 목표에서는 체력을 추정하지 않는다. 온라인 분석은 서버 재현 결과를 영수증에 저장한 값이다. 새 분석은 과거 영수증에 소급 생성하지 않는다.

### 지역 설계도·도색·도감

- 일반 작전 성공마다 해당 지역 설계도 1개, 지역 마지막 작전(06·12·18·24·30)은 2개. 실패·중단·균열 연습으로 설계도를 지급하지 않는다.
- 지역 설계도 8개로 지역 도색 1개를 확정 제작한다. 지역끼리 재료를 섞지 않는다. 제작 확인 화면, 이미 제작한 도색의 재제작 거부, 서버 요청 재시도 중복 방지 포함.
- 도색 5개 추가: 정비소의 동빛·철로의 황혼·정화의 녹빛·극저온 은빛·코어의 자주빛. 기본 대원 이미지에 지역별 색을 적용하는 도색이며 새 캐릭터 모델은 아니다. 모든 보유 대원에게 적용하고 능력치를 바꾸지 않는다. NPC 보석 상점에서는 구매할 수 없다.
- 일반 작전에서 실제 처치한 적 역할과 토벌한 지역 보스를 도감에 표시한다. 미발견 항목도 실루엣과 이름을 확인할 수 있어 수집 목표를 알 수 있다.
- 기존 고유 클리어 기록을 한 번만 읽어 지역 완료 수·설계도를 보충한다. 과거 반복 횟수는 추정하지 않는다. 기존 장비·구매·캐릭터·보석을 회수하거나 초기화하지 않는다.
- 원장에 `blueprints:지역ID`의 지급·소비·잔액을 기록한다. 계정 삭제 시 기존 원장 삭제 정책을 따른다.

### 길드 지원과 기록 카드

지원 호출 시 짧은 등장 카드와 대원 외형을 표시한다. 출격 티켓 발급 시 지원 소유자의 공개 설정을 확인한다. 공개한 경우 닉네임·칭호·프레임 색·도색을 반영하고, 비공개인 경우 기본 외형과 일반 지원 명칭을 사용한다. 지원 등록 자체는 기존처럼 길드원에게 대원 정보를 공유하는 기능이다. 차단·동일 길드·등록 여부·하루 3회 제한은 서버에서 검사한다.

지원 전투는 발급 당시 스냅샷을 사용한다. 이후 탈퇴·비공개 전환이 이미 발급한 전투의 표시나 능력을 실시간으로 바꾸지는 않는다. 새로 출격할 때 최신 설정을 적용한다.

**특수 던전 → 기록 카드**에서 현재 주에 저장된 개인 최고 점수·내 닉네임·대표 대원·칭호·도색을 PNG로 공유한다. 로컬 체험과 서버 기록을 구분해서 표시한다. 공유는 사용자가 버튼을 누를 때만 기존 Android 공유 창을 연다. 연습 점수로 정식 주간 최고 기록을 만들지 않는다.

공격 준비·공격 타이머·피격 상태에 따라 프레임을 전환하고, 돌진 회전·반동·보행 흔들림을 결합한다. 셀 경계를 측정해 스프라이트로 사용한다. 8방향 프레임이나 본 애니메이션, 모든 역할의 개별 연속 보행 시퀀스를 제작한 것은 아니다. 아트 생성은 기본 내장 도구를 사용했고 CLI/API 키는 사용하지 않았다.

## 호환과 제한

앱 0.6.0(code 6), 전투 규칙 6. 이전 버전의 진행 중 전투는 취소하고 다시 출격해야 한다. 주간 기록판은 현 전투 규칙의 기록만 비교하며 이전 달성 보상·개인 기록은 유지한다. 같은 주 안에 규칙을 바꾸는 운영 배포는 피하고, 정식 서비스에서는 주간 경계 배포를 계획해야 한다.

설계도 보상은 새 콘텐츠 수급 초안이며, 개조 조합을 포함한 성장 속도와 Android 실기기 성능은 추가 플레이테스트가 필요하다. 레이팅 기반 PvP, 길드 공동 보스, 시즌 패스, 유료 상품 확대는 이번 범위가 아니다.
