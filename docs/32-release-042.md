# 0.42.0 영어판 배포 기록

## 2026-11-26 공개 확인 및 해외 확대 제출

Play 프로덕션에서 **0.42.0 (46) - English support / Google Play에 제공됨**을 확인했다. 표시 게시일은 **11월 25일 오후 7:08**이다. 운영 최신 버전 안내도 46 / 0.42.0으로 갱신하고 서비스 health 정상 상태를 확인했다. 최소 빌드 43과 전투 규칙 30은 유지했다.

대한민국 유지 + 해외 6개국 추가를 검토 제출했다. 상품 5종의 현지 판매·가격 저장과 AdMob 승인·app-ads.txt 인증을 확인했다. 국가 변경은 아직 Google 검토 중이다. 가격표, 서버 백업, 광고 개인정보 메시지, 남은 실제 기기 검증은 [해외 배포 기록](33-overseas-release.md)에 정리했다. 아래 11월 25일 기록은 제출 당시 상태다.

## 2026-11-25 18:49 KST 확인 상태

- Play Console `io.github.hwangyeonjoon.scrapguard`의 현재 공개 버전은 **0.41.0 (45)**, 대상 국가는 **대한민국 1개**다.
- **0.42.0 (46) - English support**를 프로덕션 100% 출시로 저장하고, 영어(en-US) 기본 스토어 등록정보와 함께 **검토를 위해 변경사항 2개 전송**을 실행했다.
- 게시 개요의 **검토 중인 변경사항**에 위 두 항목이 표시된다. 최종 확인 때 Google 빠른 검사는 54%, 최대 6분 남음이었다. 화면 안내에 따르면 검사가 성공하면 심사로 전달된다. 이는 Google 승인이나 이용자 업데이트 제공 완료를 뜻하지 않는다.
- 관리형 게시는 사용 중지 상태이므로 승인 후 자동 게시된다. 국가 타기팅을 확대하거나 별도 프로모션 초안을 게시하지 않았다.

## 운영 서버

운영 `/v1/release`가 공개 버전보다 오래된 44 / 0.40.1을 안내하고 있었다. Play에서 공개를 확인한 **45 / 0.41.0**으로 최신 안내만 맞추고 최소 빌드 **43**, 규칙 **30**, `playAvailable=true`는 유지했다. **심사 중인 46을 공개 최신 버전으로 안내하지 않았다.**

- 변경 전 원격 `.env.pre-public45-20261125`, 로컬 `lightsail.env.pre-public45-20261125` 백업.
- 기존 `scrapguard-api:0.40.1` 이미지의 API 컨테이너만 재생성. DB·서버 코드·게임 규칙 변경 없음.
- 공개 `/v1/release`에서 latestBuild=45, latestVersion=0.41.0, minimumBuild=43 확인.
- `python3 Tools/service_health.py --url https://api.scrapguard.win`: API·DB·서비스 모두 정상. commerce=production, newSales=true, ads=production, RTDN=true, 환불 복구 pending=0, needsAttention=false.
- 이는 AdMob 승인이나 광고 매출 증거가 아니다.
