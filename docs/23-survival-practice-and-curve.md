# 0.38 중반 부담 완화와 무료 생존 연습

개발본 0.38.0 / Android code 41 / 전투 규칙 28. 운영 서버·Play 트랙에는 배포하지 않는다. 앱과 서버를 함께 갱신해야 하는 전투 규칙 변경이다.

## 변경 방향

무료로 같은 성장 상한과 콘텐츠에 도달하고 구매로 시간을 아껴 먼저 강해지는 방향을 유지한다. 이번에는 보급 가격·구성·구매 한도·무료 보상·강화 상한을 바꾸지 않았다. 구매 가치를 만들기 위해 무료 반복 시간을 늘리거나 모든 후반 적을 강화하지 않는다.

기존 실제 진입 장비의 지역 비교에서 오염 처리장과 중앙 공장에 일반 적 공격 부담이 집중됐다. 다만 원인을 “31작전부터 모두 성장 상한”으로 단정할 수는 없다. 저장된 진입 장비의 성장 정도는 조작과 경로마다 다르다. 같은 장비·시드로 변경 전후를 비교하고, 보스·생존 작전과 피해 출처를 나눠 본다.

| 구간 | 변경 |
|---|---|
| 오염 처리장 13~18 | 일반 적 공격 피해 15% 감소. 최소 예고 1.6→2.1초, 새 예고 사이 대기 0.8→1.15초 |
| 중앙 공장 25~30 | 일반 적 공격 피해 10% 감소. 최소 예고 1.6→1.9초, 새 예고 사이 대기 0.8→1초 |
| 중앙 공장 조립기 | 소환 간격 9→11초, 소환 방패기 기본 체력 70→50, 살아 있는 소환체 최대 8기 |
| 36·42·48·54 마지막 보스 | 체력 +8·12·16·20%, 공격 피해 +4·6·8·10% |
| 최종 지역 55~60 보스 | 체력 +8~24%, 공격 피해 +4~12%로 점진 증가 |

중반 완화는 지형·접촉·보스 피해를 깎는 변경이 아니다. 자폭 적의 동작 예고도 실제 공격 지연과 맞췄다. 같은 조건 실력전과 극한 작전의 기존 규칙은 유지한다. 후반 일반 무리는 성장한 힘을 느낄 구간으로 남기며, “마지막 지역이 무조건 가장 낮은 승률”이 되도록 맞추지는 않는다.

## 실패 뒤 무료로 배우는 경로

- 패배 화면과 전투 분석에서 해당 작전의 **60초 생존 연습** 또는 보스 연습으로 바로 진입한다. 성장 화면에서도 열린 작전을 선택할 수 있다.
- 생존 연습은 현재 장비와 정해진 기본 스킬로 지역 일반 적의 공격을 연습한다. 초반 대기 대신 중반에 가까운 소환 밀도로 시작하고 처음 3초는 준비 시간을 준다. 로봇·지원·광고 부활·현장 임무·포위 웨이브는 제외한다. 전체 작전 재현이나 밸런스 승률 표본이 아니다.
- 연습은 입장 비용이 없고, 골드·부품·보석·현장 보급 시간·일일 임무·작전 진행·로봇 전시 기록을 지급하지 않는다. 서버가 입력을 재생하며 같은 연습 결과 재요청으로 보상을 만들 수 없다.
- 전투 분석에 최근 8초의 피해 출처를 추가했다(저장 상한 최근 32회). 전체 전투의 피해 종류도 유지한다. 영상 재생 기능은 아니다.
- 적의 독성 폭발과 실제 지형 피해를 구분해 안내한다. “독 피해이므로 바닥을 피하라”는 잘못된 연결을 없앴다.

## 측정 자료

- [무료 경로 실제 장비 800개 전후 비교](reports/curve038-free.md)
- [구매 경로 실제 장비 160개 전후 비교](reports/curve038-paid.md)
- [18~24작전 70개 진입 상태의 무료·구매 시간 가치](reports/curve038-value.md)

무료/구매 장비 비교는 기존 0.36 달력에서 얻은 장비를 복원하고 0.37과 0.38 전투를 비교한다. 새로운 28일 달력 전체를 돌린 자료가 아니므로 완료 날짜나 장기 수요를 새로 보장하지 않는다. 구매 경로는 더 이른 날짜에 진입할 수 있어 무료 경로와 직접 승률을 빼면 현금의 효과가 되지 않는다. 구매 시간 가치는 같은 장비·지갑에서 시작하는 별도 비교로 확인한다.

무료 경로 장비의 오염 처리장 승리는 자연 22→25/40, 회피 24→33/40이다. 저체력 시간 비율 중앙값도 각각 9.0→3.1%, 20.0→12.3%로 줄었다. 중앙 공장은 자연 13→16/40, 회피 30→33/40이다. 중앙 공장의 자연 조작 저체력 비율은 14.9→15.4%로 줄지 않았으며, 해당 지역은 여전히 고비다.

후반 무료 경로의 자연 조작은 자력 선별장 28→26/40, 폭풍 송전탑 33→31/40, 궤도 23→22/40이다. 궤도 회피 조작은 35→34/40이다. 중반의 돌출을 완화하고 후반 보스 부담을 높였으나, 지역 승률이 일렬로 내려가는 곡선으로 완성됐다는 뜻은 아니다. 중앙 공장과 최종 보스의 사람 체감은 계속 관찰해야 한다.

예고·소환만 조정한 초기 비교안 A도 측정했으나 자연 조작의 중반 부담을 충분히 줄이지 못했다. 최종안 B에는 위 15%·10% 일반 적 피해 감소를 추가했다. A와 B는 합산하지 않는다. 작전·조작당 10시드이므로 1~2승 차이를 확정적인 개선으로 보지 않는다.

18~24작전 시간 가치 재검증에서는 70개 시작 상태 모두 무료로 구매와 같은 무기 레벨에 도달했다. 보급 한 번이 생략하는 반복은 중앙값 2판, 작전별 약 7.9~9.9분이다. 의상에 보석을 사용한 경로도 70개 모두 무료 경로와 도달 시간·승패가 같았다. 구매 후 똑같이 반복하면 추가 강화 재료를 얻지만, 매 시드의 승리가 단조롭게 늘지는 않는다. 새로운 난이도에서도 구매를 시간 절약 수단으로 유지할 근거이며, 사람의 만족도나 판매량 증명은 아니다.

구매 경로 장비의 18작전 회피 승리는 7→9/10, 30작전은 7→8/10이었다. 후반 자연 조작의 42작전은 8→5/10, 54작전 7→5/10, 60작전 2→1/10으로 어려워졌다. 후반 회피 조작은 36~54작전 10/10, 60작전 9/10을 유지했다. 잘 피하면 성장의 효과를 유지하지만, 마지막 보스가 자연 조작에 이미 어려웠다는 한계도 함께 남긴다. 이 수치만 보고 추가로 보스 체력을 올리지 않는다.

재현할 때 `Tools/regional_review.py report`는 무료 800개 행의 누락·중복·장비 불일치를 거절한다. `Tools/curve_review.py`는 구매 장비 160개와 시간 가치 280개 경로의 완전성, 동일 시작 상태·장비·지출을 확인한다. 실제 판 수와 독립 시드 수는 구분한다.

```sh
python3 Tools/regional_review.py report docs/reports/curve038-free-inputs.json.gz docs/reports/region037-expanded-after.json.gz docs/reports/curve038-free-after.json.gz docs/reports/curve038-free.md
python3 Tools/curve_review.py paid docs/reports/curve038-paid-inputs.json.gz docs/reports/curve038-paid-after.json.gz docs/reports/curve038-paid.md --before docs/reports/curve038-paid-before.json.gz
python3 Tools/curve_review.py value docs/reports/curve038-value-inputs.json.gz docs/reports/curve038-value.json.gz docs/reports/curve038-value.md
```

변경 전 구매 장비 비교는 `499814b` 코어를 별도 임시 폴더에 복원하고 같은 `RegionalAudit` 측정기를 사용했다. 첫 비교안은 `curve038-candidate-a-*` 원본으로 보존하며 최종 보고서는 `curve038-*-after`를 사용한다.

## 구현 검증

코어 132개, Unity EditMode 172개, 서버 407개 검사를 통과했다. 연습의 무료 진입·모드 구분·60초 종료·서버 재생·중복 정산·성장 보상 차단, 최근 피격 기록과 적/지형 안내 구분을 포함한다. 기존 지역 집계 검사 4개와 새 집계 도구의 누락·중복·장비·지갑·지출 변조 거절도 확인했다.

Android QA와 직접 조작용 체험 APK는 각각 118,430,793 bytes와 118,429,605 bytes다. arm64, v2 서명, 16KB ZIP/ELF 정렬, 백업 차단 검사를 통과했다. QA는 화면/전투 자동 실행용이고 참가자에게는 `Builds/Android/ScrapGuard-playtest.apk`를 제공한다. 둘 다 운영 앱과 다른 `.qa` 패키지이며 실결제가 연결되지 않는다.

[Android 실행 기록](reports/android038-runtime/README.md)은 실제 IL2CPP 앱에서 확인한 화면·연습·입력 재생과 에뮬레이터 부하 측정을 모은 자료다. 패키지 검사 JSON의 `device_execution: not tested`는 해당 파일 검사 도구의 범위이며 런타임 결과는 별도로 기록한다. 수동 체험판의 현장 보급 안내는 “보스 연습 제외”를 “모든 연습 제외”로 정리했다.

Android 화면/연습/구매·강화 검사는 오류 0건, 입력 18개는 .NET 재생과 일치했다. 밀집 구간 최대 적은 240마리다. host GPU 평균은 냉각 57.2, 용광로 56.1, 궤도 49.4 FPS였다. 궤도 밀집 p99는 83.3ms, 일반 스폰 p99는 150ms로 남아 있으므로 성능 최적화 완료나 실물 폰 합격으로 표시하지 않는다. 검증 후에는 전용 에뮬레이터에 수동 체험 APK를 설치했다.

## 사람과 실물 폰에서 남은 확인

사람 테스트·실물 폰 검증은 **미실시**다. 참가자를 대신 만들거나 에뮬레이터 결과를 실물 폰 결과로 표시하지 않는다. 수동 체험 APK를 사용하고, 기존 관찰표에 아래 항목을 우선한다.

1. 13~18 생존 작전: 어떤 공격에 맞았는지 스스로 설명하는가. 패배 뒤 무료 연습을 스스로 발견하는가. 연습 뒤 실제 작전에서 피하는 행동이 달라지는가.
2. 25~30: 소환 방패기 때문에 길이 막힐 때 조립기를 먼저 처리하는가. 예고를 읽을 시간이 있는가.
3. 냉각 방패의 측면 약점을 알아채는가. 패배 후 무료 연습·강화·보급 중 무엇을 선택하고, 보급을 도움 또는 압박으로 느끼는가.
4. 중저가 실물 폰에서 냉각·용광로·궤도 밀집 구간을 15분 직접 조작해 프레임·발열·터치를 기록한다. 기기 모델·OS·빌드·영상 여부를 함께 남긴다.

| 참가자 | 중반 장비·작전 | 사망 원인 설명 | 도움 전 연습 발견 | 연습 뒤 재도전·행동 변화 | 구매 압박 느낌 | 기기·영상 |
|---|---|---|---|---|---|---|
| P1 | 미실시 | 미실시 | 미실시 | 미실시 | 미실시 | 미실시 |
| P2 | 미실시 | 미실시 | 미실시 | 미실시 | 미실시 | 미실시 |
| P3 | 미실시 | 미실시 | 미실시 | 미실시 | 미실시 | 미실시 |

첫 플레이 신규 계정 관찰과 중반 장비로 시작하는 집중 관찰은 구분한다. 테스트 보석은 실제 결제가 아니며, 참여자의 보석 사용을 현금 구매 전환율로 해석하지 않는다.
