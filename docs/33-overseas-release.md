- 대한민국을 유지하고 **미국·캐나다·오스트레일리아·뉴질랜드·싱가포르·필리핀**을 추가했다. 약 09:48 KST에 국가 변경 1건을 검토 제출했고, 최종 재확인에서도 **검토 중인 변경사항 / 6개 국가·지역 추가**다. 사전 검사 진행 표시가 끝나고 실제 검토 중 안내로 바뀌었다. **해외 공개 승인 완료가 아니다.** 관리형 게시가 꺼져 있어 승인 후 자동 반영된다. 프로덕션과 국가 설정을 공유하는 다른 트랙에도 영향을 준다는 Console 안내를 확인했다.

- AdMob의 고철 수호대 상태는 **준비됨 / 광고 게재 사용 설정됨**이다. `https://api.scrapguard.win/app-ads.txt`는 **파일을 찾아서 확인했습니다**, 승인 쿼리 100%로 표시됐다. 이전 app-ads.txt 인증 대기는 해소됐다.
- AdMob 미국 주 메시지 **Scrap Guard - US privacy choices**를 고철 수호대 한 앱에만 영어(en-US)로 게시했다. 목록에서 **게시됨 / 게시 전환 on**을 확인했다. 현재·향후 지원되는 미국 주를 대상으로 한다. 빈틈배송 설정은 변경하지 않았다.
- 운영 최신 버전 안내를 **46 / 0.42.0**으로 갱신했다. 최소 빌드 43, 전투 규칙 30, API 이미지 `scrapguard-api:0.40.1`은 유지했다. 앱 재빌드 없이 공개된 영어판을 사용한다.

### 서버 반영과 검증

실제 운영 env는 `/opt/scrapguard/Server/Deploy/.env`다. 같은 폴더의 `.env.pre-public46-20261126`과 로컬 비공개 `lightsail.env.pre-public46-20261126`으로 백업한 뒤 최신 빌드·버전·한영 업데이트 안내만 변경했다. Compose의 API 컨테이너만 재생성했고 DB·게임 규칙·가격 코드는 변경하지 않았다. 비밀값과 env 파일은 Git에 넣지 않는다.

- 공개 `/v1/release`: latestBuild=46, latestVersion=0.42.0, minimumBuild=43, combatRules=30, playAvailable=true 확인.
- `python3 Tools/service_health.py --url https://api.scrapguard.win`: API·DB·서비스 정상, commerce=production, newSales=true, ads=production, RTDN=true, 환불 pending=0, missingTokens=0, needsAttention=false.
- 미국 메시지는 Console 게시만 검증했다. 기존 UMP/광고 TFUA=true, 콘텐츠 등급 G를 유지했다. TFUA가 적용되는 요청에서는 메시지가 표시되지 않을 수 있으므로 **게시됨을 실제 미국 기기 동의 흐름 통과로 해석하지 않는다.** 개인화 광고로 전환하지 않았고, 모든 해외 법적 요건 충족을 판정한 것도 아니다.
- 이번 작업에서 실제 구매·환불·구매 복원·광고 보상 지급을 새로 실행하지 않았다. 외국 Play 계정의 설치·현지 가격·광고/개인정보 선택 동작 검증은 남아 있다.
- 영어 스크린샷은 기존 한국어 애셋 상속 상태다. 국가 추가 승인과 영어 이미지 개선을 구분한다.

## 광고 개인정보 처리 확인

`RewardedAds.cs`는 현재 UMP와 광고 요청 모두 TFUA=true를 적용하며 광고 콘텐츠 등급 G를 사용한다. Google 문서상 UMP TFUA=true이면 동의 메시지를 요청하지 않는다. 국가 확대를 이유로 이를 false로 바꾸거나 개인화 광고를 활성화하지 않았다. 이는 해외 모든 법적 요건 충족이나 AdMob 승인 완료를 의미하지 않는다.

AdMob 콘솔의 미국 주별 규정 설정과 실제 앱 승인 상태는 재확인이 필요하다. 유럽경제지역·영국·스위스 확대는 이번 기본 6개국 범위에 포함하지 않았다. 추후 확대 시 해당 지역 동의/연령 처리와 콘솔 메시지를 함께 확인한다.

공식 참고:
- [Play 국가/지역 타기팅](https://support.google.com/googleplay/android-developer/answer/7550024?hl=en): 프로덕션 국가 설정은 현재와 향후 릴리스에 적용되므로, 46 승인 전 변경하면 기존 45가 해외에 노출될 수 있음.
- [Google UMP의 연령 동의 처리](https://developers.google.com/admob/unity/privacy/gdpr).

## 콘솔 연결 복구 후 실행 순서

1. 46 심사/공개 상태 확인. 영어판 승인과 국가 확대 변경을 묶을 수 있는지 확인하고, 45 한국어판이 먼저 해외 공개되지 않도록 제출/게시 상태를 확인한다.
2. 프로덕션 국가에 한국 유지 + 위 6개국 추가. 신규 약관·규제 선언이 나오면 내용을 확인하며 사실을 추정해 선언하지 않는다.
3. `gems_300`, `gems_600`, `gems_1200`, `gems_2600`, `ad_skip_lifetime` 각 standard 구매 옵션의 6개국 판매 및 가격 설정 확인. 한국 가격 유지, 신규 통화 가격은 Google 환산 미리보기를 확인해 저장하고 실제 금액 기록.
4. AdMob 앱 승인·국가별 개인정보 설정 점검. 영어 지원 링크 공개 확인.
5. 국가 변경 검토 제출 후 게시 개요에서 실제 저장/검토 상태 확인. 심사 요청과 승인 완료를 구분한다.
6. 46 실제 공개 확인 후 운영 최신 버전 안내 갱신. 외국 Play 계정의 설치·상품 가격 확인은 별도 실제 검증으로 남긴다.
