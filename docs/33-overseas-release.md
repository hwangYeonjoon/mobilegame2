# 해외 배포 준비 · 2026-11-25

## 범위와 실제 상태

사용자가 영어 지원 배포에 이어 해외 국가 확대를 요청했다. 우선 미국·캐나다·호주·뉴질랜드·싱가포르·필리핀 6개국을 제안했고, 별도 선호가 없으면 이 범위로 진행한다고 안내했다. 대한민국은 유지한다. **아직 Play 국가 설정을 변경하지 않았다.**

- 마지막 Play 직접 확인: 18:49 KST, 공개 0.41.0 (45), 대한민국만 제공. 0.42.0 (46) 영어판과 영어 스토어 등록정보는 검토 요청 후 검사/심사 대기. [배포 기록](32-release-042.md) 참조.
- 이번 국가 확대 작업에서는 브라우저 호스트가 unavailable, Chrome 네이티브 접근도 `cgWindowNotFound`로 실패했다. 사용자에게 Mac 잠금 해제와 가운데 Console 창 표시를 요청했다. 새 버전 승인 여부와 판매 국가를 추측하지 않았다.
- 5개 상품의 영어 설명은 앞 작업에서 저장했지만, 구매 옵션의 해외 가격/판매 국가는 아직 추가하지 않았다. 한국 가격 변경 없음.

기존 한국어 페이지와 홈페이지에 English 링크, 영어 페이지에 한국어 링크를 추가했다. 개인정보 안내는 11월 5일 한국어 방침의 번역이며 새 수집·보관 관행을 선언하지 않는다. 홈페이지의 오래된 ‘테스트 준비 단계’ 문구도 공개 상태에 맞춰 정리했다.

계정 삭제 스크립트는 문서 언어에 따라 확인·진행·결과 문구만 전환한다. 복구 코드 인증, 영구 삭제 확인, 입력 초기화, same-origin DELETE, no-store, credentials=omit, redirect=error, 15초 제한과 중복 제출 방지는 유지했다. 실제 운영 계정 삭제는 하지 않았다.

운영 Caddy에 영어 경로 3개만 허용했다. CSP와 기존 보안 헤더, API 라우팅을 유지했다. 운영 원본 백업은 `/opt/scrapguard/backups/site-pre-en-20261125/`, 업로드 임시본은 `/home/ubuntu/scrapguard-en-20261125/`다. 변경 전후 Caddy validate 통과 후 Caddy만 재시작했다. API 이미지·DB·앱 번들 변경 없음.

### 검증

- Node VM 모의 삭제 검증 14개 통과: 한국어/영어 각각 성공, 401, 429, 503, 기타 오류, 확인 취소, 네트워크 오류. 네트워크·실계정 삭제 없이 요청 경로/인증 헤더/입력 초기화/재시도 상태 확인.
- 모든 로컬 HTML 내부 링크와 정적 파일 경로 존재 확인.
- 운영 영어 페이지 3개와 삭제 JS 응답이 로컬 파일과 바이트 단위 일치.
- 운영 응답에 CSP, X-Frame-Options DENY, nosniff, no-referrer 확인.
- 운영 health: API·DB·서비스 정상, commerce=production, newSales=true, ads=production, RTDN=true, 환불 pending=0.
- `/v1/release`: latestBuild=45, minimumBuild=43, combatRules=30 유지. 46 공개를 확인하기 전 안내 버전을 올리지 않음.
- 브라우저 창에 접근하지 못해 영어 웹페이지 육안 확인과 Play 외국 계정 설치·구매 검증은 미실시.

## 광고 개인정보 처리 확인

`RewardedAds.cs`는 현재 UMP와 광고 요청 모두 TFUA=true를 적용하며 광고 콘텐츠 등급 G를 사용한다. Google 문서상 UMP TFUA=true이면 동의 메시지를 요청하지 않는다. 국가 확대를 이유로 이를 false로 바꾸거나 개인화 광고를 활성화하지 않았다. 이는 해외 모든 법적 요건 충족이나 AdMob 승인 완료를 의미하지 않는다.

AdMob 콘솔의 미국 주별 규정 설정과 실제 앱 승인 상태는 재확인이 필요하다. 유럽경제지역·영국·스위스 확대는 이번 기본 6개국 범위에 포함하지 않았다. 추후 확대 시 해당 지역 동의/연령 처리와 콘솔 메시지를 함께 확인한다.

공식 참고:
- [Play 국가/지역 타기팅](https://support.google.com/googleplay/android-developer/answer/7550024?hl=en): 프로덕션 국가 설정은 현재와 향후 릴리스에 적용되므로, 46 승인 전 변경하면 기존 45가 해외에 노출될 수 있음.
- [Google UMP의 연령 동의 처리](https://developers.google.com/admob/unity/privacy/gdpr).

## 콘솔 연결 복구 후 실행 순서

1. 46 심사/공개 상태 확인. 영어판 승인과 국가 확대 변경을 묶을 수 있는지 확인하고, 45 한국어판이 먼저 해외 공개되지 않도록 제출/게시 상태를 확인한다.
2. 프로덕션 국가에 한국 유지 + 위 6개국 추가. 신규 약관·규제 선언이 나오면 내용을 확인하며 사실을 추정해 선언하지 않는다.
3. `gems_300`, `gems_600`, `gems_1200`, `gems_2600`, `ad_skip_lifetime` 각 standard 구매 옵션의 6개국 판매 및 가격 설정 확인. 한국 가격 유지, 신규 통화 가격은 Google 환산 미리보기를 확인해 저장하고 실제 금액 기록.
4. AdMob 앱 승인·국가별 개인정보 설정 점검. 영어 지원 링크 공개 확인.
5. 국가 변경 검토 제출 후 게시 개요에서 실제 저장/검토 상태 확인. 심사 요청과 승인 완료를 구분한다.
6. 46 실제 공개 확인 후 운영 최신 버전 안내 갱신. 외국 Play 계정의 설치·상품 가격 확인은 별도 실제 검증으로 남긴다.

영어 스토어 이미지는 여전히 기존 한국어 애셋 상속이며 영어 실플레이 스크린샷 교체가 남아 있다. QA 워터마크 이미지는 스토어에 쓰지 않는다.
