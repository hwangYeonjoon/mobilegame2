# 0.35 순수 외형 팩과 선택형 극한 작전

개발본 0.35.0 / Android code 38 / 전투 규칙 26. 운영 서버·Play 트랙 미배포.

## 상품

성운 기사 팩은 600보석에 3기체 외형만 지급한다. 골드 18,000·부품 180 묶음을 제거했다. 구매 전 외형 3종·가격·잔액·능력치 없음이 표시되며 구매 후 즉시 적용한다. 소유 키 `robot_style_astral`과 기존 권리는 보존한다. 기존 성장 보급·작전 패스는 유지하므로 전체 BM이 외형 전용이라는 뜻은 아니다. 구매해도 자동 강화하지 않는다.

## 일반 진행과 고난도 분리

43~60작전 전체를 일괄 상향하지 않았다. 일반 48·54·60작전은 체력 절반 이하 보스의 직선 공격 뒤 1.2초 추가 예고를 둔 표적 원 하나를 추가한다. 일반 보스 체력·피해 배율은 그대로다. 해당 일반 작전을 완료하면 별도 극한 모드를 무료로 연다. 성장 상한은 권장 조건이며 입장 제한은 아니다. 본인 장비로 일반과 같은 전투 시간 동안 스킬·로봇을 조립한다.

| 극한 | 보스 체력 배율 | 보스 피해 배율 | 기본 예고 | 후속 원 반경 |
|---|---:|---:|---:|---:|
| 48 | 1.15 | 1.35 | 1.8초 | 85 |
| 54·60 | 1.30 | 1.65 | 1.5초 | 100 |

극한에서는 체력 조건 없이 후속 원을 사용한다. 후속 예고는 기본 예고보다 0.8초 뒤이며 원의 원시 피해는 240이다. 배율·방어 계산은 공용 코어에서 처리한다. 지원과 광고 부활은 사용하지 않는다. 순위는 기존 동일 조건 실력전과 분리한다.

각 극한 최초 완료에 코어 파편 6개, 3종 완료에 `극한의 조립사` 칭호를 준다. 반복 완료는 최고 시간·사용 조합 기록만 갱신한다. 일반 작전·길드 점수·주간 순위를 대신 진행하거나 일반 골드·부품을 지급하지 않는다. 60초 이상 전투의 무료 현장 보급 시간은 쌓인다. 파편은 기존 주간 모드에서도 얻으므로 극한이 외형 제작의 유일한 길은 아니다.

서버는 시작 상태와 입력을 재생해 결과를 판정하고 첫 보상·재요청·재시작 이후 중복을 검사한다. 실제 Unity 극한 54 승리 입력을 서버 통합 검사 fixture로 보존했다. 로컬 승리 필드만으로 보상을 주지 않는다. 구버전 저장은 극한 기록 목록을 초기화하며 기존 칭호 인덱스는 유지한다.

## 동일 조건 비교

[요약 표](reports/content035-audit.md), [수정 전](reports/content035-before.json.gz), [최종](reports/content035-after.json.gz), [초기 극한 진단](reports/content035-initial-hard.json.gz).

0.34의 42작전 실제 완료 스냅샷을 사용해 도달 장비와 상한 장비를 분리했다. 상한은 대원 30·장비 20이며 원래 장비 종류와 등급은 유지한다. 전체 경제 진행을 다시 모의한 결과가 아니라, 세 지역 최종 보스의 독립 비교다. 조건당 10시드, 일반 전후 각각 120판과 극한 60판이다.

일반 승리는 도달 장비 회피 29/30·자연 20/30, 상한 장비 회피 28/30·자연 20/30으로 수정 전후 같다. 일반 긴장감이 개선됐다는 증거는 부족하다. 극한 상한 장비는 회피 26/30·자연 3/30이다. 초기 극한 48 회피 4/10이 지나치게 낮아 48만 완화했고 최종 8/10이 됐다. 54·60은 각각 9/10이다. 이는 봇 간 실력 격차이며 실제 이용자의 예상 승률은 아니다.

## 검증

공유 코어 125개, Unity EditMode 164개, 서버 396개 통과. 서버 검사는 실제 Unity 극한 승리의 최초 파편 지급, 재요청, 두 번째 도전과 저장소 재시작을 포함한다. 최종 macOS 빌드 UI 55화면 오류 0개, 기록 15개의 Unity→.NET 재생 일치를 확인했다. 극한 3종은 실제 시작부터 종료까지 기록했고 나머지 신규 보스 6개는 보스 구간용 probe다. 결과는 `reports/runtime035/`에 보존한다. Android QA와 직접 조작용 체험 APK 빌드는 모두 성공했다. 각각 약 109.62MiB이며 버전 0.35.0/code38·arm64·서명·16KB ZIP/ELF 정렬 검사를 통과했다. [QA 패키지 검사](reports/apk035-qa.json), [체험 패키지 검사](reports/apk035-playtest.json). QA 설치는 성공했지만 전용 에뮬레이터에서 Android System UI 응답 없음이 발생했고 GrowthUI 결과는 생성되지 않았다. Android 실행·전투 검증은 **미완료**다. [오류 화면](reports/runtime035/android-system-ui-anr.png)과 [실행 상태](reports/runtime035/android-execution.json)를 보존한다. macOS 검증을 Android 또는 실기기 성공으로 대신하지 않는다.

## 남은 한계

사람·실물 Android 기기 테스트는 미실시다. 봇 승률만으로 재미·반복 도전 의향·외형 가격 수용성을 판단하지 않는다. 일반 후반을 강제 장벽으로 바꾸지는 않았으며 극한의 자연 조작 3/30은 숙련 요구가 높다는 신호다. 이 세 작전이나 1회 파편 보상만으로 장기 콘텐츠·매출이 해결됐다고 주장하지 않는다.
