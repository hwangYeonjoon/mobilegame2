## 앱 출시

- 소스 `8dff409`, Android 0.41.0 / code 45 / 전투 규칙 30.
- 전날 검증한 서명 AAB를 그대로 업로드했다. 106,121,556 bytes, SHA-256 `d5464a1f7a73a5467d059923511fa9acde2dda4319a28977211cfc7d2a77b6c9`.
- Play가 45(0.41.0), min SDK 26, target SDK 36, ARM64로 인식했다. 지원 기기의 추가·제외는 모두 0이다.
- Play 표시 신규 설치 크기 105MB, 이전 대비 +20.1KB, 업데이트 크기 26.2MB. 가독화 파일·네이티브 디버그 기호 미등록 경고 2개를 확인했다. 출시 차단 오류는 없었다.
- 한국어 출시 노트와 프로덕션 전체 출시(100%)를 저장하고 **검토를 위해 변경사항 전송**을 실행했다. 게시 개요에 `검토 중인 변경사항 / 0.41.0 (45) - 로봇 도감과 강화 동선 / 전체 출시 시작`이 표시됐다. 당시 빠른 사전 검사 진행 중으로, 검사 성공 후 심사 전송되는 상태다.
- 이후 재확인에서 사전 검사 진행 표시가 없어지고 `변경사항을 검토 중입니다. 앱을 검토하는 과정에서 추가 문제가 발견될 수도 있습니다.`로 바뀌었다. Google 검토 단계 진입을 확인했다.
- 같은 날 공개한 YouTube 영상을 기본 스토어 등록정보에 추가하고 검토를 다시 요청했다. Google의 검토 재시작 안내를 확인한 뒤 진행했으며, 최종 게시 개요에는 **프로덕션 45 전체 출시 + 한국어 기본 등록정보 동영상 변경** 두 항목이 `검토 중인 변경사항`으로 표시됐다. 이 추가 전송 시점에는 빠른 사전 검사가 다시 진행 중이었다. 최초 요청과 최종 요청을 별개의 공개 완료로 해석하지 않는다.
- 관리형 게시가 사용 중지되어 승인 후 자동 게시된다. **이 기록은 45의 공개 완료를 뜻하지 않는다.**

- 45 공개가 늦어지면 행사 시작일도 함께 미뤄야 한다. 초안 일정은 노출 확정이나 예약 게시 완료가 아니다.

## 이어서 할 일

채널 디자인 후속 작업: 같은 날 [프로필·배너와 홈 구성](../Store/Channel/README.md)을 게시하고 공개 채널에서 확인했다. 공개 홈 영상에서 한국어 자막과 설명의 외부 링크 표시도 확인했다. 앱 45의 승인·공개 상태는 이 채널 꾸미기 작업에서 다시 판단하지 않았다.

1. Google의 45 및 기본 스토어 영상 승인·게시 확인. 실제 공개 뒤 운영 latestBuild만 45로 갱신하고 최소 버전은 별도 필요가 없으면 43 유지.
2. 프로모션의 앱 공개 시점·일정을 다시 확인하고 AI 이미지 라벨 지정 후 제출. 노출 및 신규 유입은 실제 보고서로 확인한다.
3. 공개 영상 자막 전파와 채널 외부 링크 기능을 재확인한다. 추가 신원 확인이 요구되면 사용자가 직접 완료한다.
