# 0.41.0 출시 검토와 홍보 등록 — 2026-11-25

## 앱 출시

- 소스 `8dff409`, Android 0.41.0 / code 45 / 전투 규칙 30.
- 전날 검증한 서명 AAB를 그대로 업로드했다. 106,121,556 bytes, SHA-256 `d5464a1f7a73a5467d059923511fa9acde2dda4319a28977211cfc7d2a77b6c9`.
- Play가 45(0.41.0), min SDK 26, target SDK 36, ARM64로 인식했다. 지원 기기의 추가·제외는 모두 0이다.
- Play 표시 신규 설치 크기 105MB, 이전 대비 +20.1KB, 업데이트 크기 26.2MB. 가독화 파일·네이티브 디버그 기호 미등록 경고 2개를 확인했다. 출시 차단 오류는 없었다.
- 한국어 출시 노트와 프로덕션 전체 출시(100%)를 저장하고 **검토를 위해 변경사항 전송**을 실행했다. 게시 개요에 `검토 중인 변경사항 / 0.41.0 (45) - 로봇 도감과 강화 동선 / 전체 출시 시작`이 표시됐다. 당시 빠른 사전 검사 진행 중으로, 검사 성공 후 심사 전송되는 상태다.
- 이후 재확인에서 사전 검사 진행 표시가 없어지고 `변경사항을 검토 중입니다. 앱을 검토하는 과정에서 추가 문제가 발견될 수도 있습니다.`로 바뀌었다. Google 검토 단계 진입을 확인했다.
- 관리형 게시가 사용 중지되어 승인 후 자동 게시된다. **이 기록은 45의 공개 완료를 뜻하지 않는다.**

- Play Console에서 0.40.1(44)의 `Google Play에 제공됨`, 100%, 2026-11-24 오후 2:44 게시를 확인했다.
- 운영과 로컬 비공개 배포 env의 최신 버전을 43/0.40.0에서 **44/0.40.1**로 갱신했다. 최소 버전 **43**, 규칙 **30**, `playAvailable=true`는 유지했다. 승인 전 45를 요구하지 않는다.
- 운영 `.env.pre-public44-20261125`, 로컬 `lightsail.env.pre-public44-20261125`에 변경 전 설정을 보관했다. 기존 서버 이미지 `scrapguard-api:0.40.1`의 API 컨테이너만 재생성했다. 전투·경제·가격·광고 설정이나 DB를 바꾸지 않았다.
- 공개 `/v1/release` 응답의 latestBuild=44, minimumBuild=43을 확인했다. `Tools/service_health.py`의 API·DB·서비스 검사 모두 정상, commerce=production, newSales=true, ads=production, RTDN=true, 환불 복구 pending=0, needsAttention=false다. 이 검사는 AdMob 앱 승인이나 광고 매출을 증명하지 않는다.

## 홍보 콘텐츠

- Play에 `로봇 도감과 조립 목표 0.41` **초안을 저장**했다. 임시 ID `4831549310827165691`.
- 주요 업데이트 → 기능 및 공지사항, 대한민국/한국어. 2026-11-30 01:07 UTC(한국 10:07)부터 2026-12-28 01:07 UTC까지 28일이다. 시작 전 미리보기는 끄고 추천 노출은 요청하지 않았다.
- 기존 태그라인 33자와 설명 226자, `primary-1920x1080.jpg`를 입력했다. Play가 1920×1080, 16:9를 인식했고 기본 이미지에서 텍스트를 찾지 못했다는 검사 결과를 확인했다.
- 그림은 AI 생성 홍보 일러스트다. 최종 `AI 애셋 선언`은 해당 이미지에 라벨을 지정한 뒤 제출해야 한다. 라벨 선택과 제출이 한 단계로 연결되어 있어, 앱 공개 및 영상 연결 전에는 **제출하지 않았다**. 미선언 상태를 'AI 미사용'으로 저장하지 않았다.
- 45 공개가 늦어지면 행사 시작일도 함께 미뤄야 한다. 초안 일정은 노출 확정이나 예약 게시 완료가 아니다.

## 영상 연결 대기

- 기존 개인 YouTube 채널 **이선생**(`UCNFKX_NnUQPGwRyEz0ADE9g`)을 확인했다. 별도 채널은 만들지 않았다.
- YouTube가 업로드 전 추가 본인 확인을 요구했고 패스키 요청은 `요청 제한 시간 초과`로 끝났다. 사용자의 직접 인증 완료가 필요하다.
- 동영상 제출 화면의 서비스 약관 동의에 대해 사용자에게 확인을 요청했다. 아직 답변이 없어 영상을 제출하지 않았다.
- 따라서 YouTube 영상 URL, Play 스토어 동영상 연결, 프로모션 영상 연결은 **미완료**다. 준비 영상의 파일·해시·실제 플레이 출처는 [홍보 폴더](../Store/Promotions/robot-codex-041/README.md)를 따른다.

1. 사용자 본인 확인 및 YouTube 제출 약관 동의 후 가로형 영상 업로드, 한국어 자막, 공개/임베드 허용, 광고 수익화 해제 확인.
