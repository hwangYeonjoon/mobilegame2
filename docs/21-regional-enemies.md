# 0.37 지역별 기계 군단

개발본 0.37.0 / Android code 40 / 전투 규칙 27. 운영 서버와 Play 트랙에는 배포하지 않았다. 무료로 진행하고 구매로 시간을 아끼며 성장하는 BM은 유지한다.

## 외형과 전투

일반 적의 공통 역할 6종은 유지하면서 10개 지역 × 6역할의 기본 외형을 만들었다. 모두 다른 적 60종을 한꺼번에 스폰한다는 뜻은 아니다. 기존 지역별 편성, 초반 추격형 대체, 돌진 순찰, 소환 규칙에 해당하는 역할만 등장한다. 미사용 역할 칸은 공통 아틀라스의 예비 외형이다. 보스 전용 그림과 보스 난이도 곡선은 유지한다.

| 지역 | 기계 소재 | 대표 행동 |
|---|---|---|
| 고철 정비소 | 톱날·용접기·작업대 장갑 | 절단 집게봇이 접근 후 정지, 1.8초 예고 뒤 반경 48 절단. 첫 25초에는 사용하지 않음 |
| 폐철도 | 철도 바퀴·기관차·신호등 | 폭주 운반차가 가로/세로 축으로 방향을 고정하고 1.15초 예고 후 직선 돌진 |
| 오염 처리장 | 여과기·폐수 탱크·밀폐판 | 누출 운반기가 2초 예고 후 반경 70 누출. 지속 바닥 장판은 남기지 않음 |
| 냉각 시설 | 방열핀·냉각기·절연 장갑 | 방패기가 2.2초 멈춰 한 방향을 방어. 플레이어 위치 기준 정면 55% 감쇄, 측면·후면과 방어 해제 시 정상 피해 |
| 중앙 공장 | 프레스·조립 팔·금형 | 장갑 조립기가 추격형 대신 약한 방패기 1기를 생산 |

| 심층 용광로 | 주조 도구·용탕 통·내열판 | 용탕 운반기가 2초 예고 후 반경 96 분출 |
| 자력 선별장 | 자석·견인 장치·집게 | 견인차가 비스듬히 접근하고 1.15초 예고 후 짧게 돌진 |
| 폭풍 송전탑 | 풍차·피뢰침·송전 구조물 | 포대가 2초 예고 후 세로 28×200 낙뢰 |
| 궤도 조립항 | 추진기·위성 패널·화물 팔 | 조립기가 추격형 대신 돌진 차량 1기를 내보냄. 소환 직후 2초 준비 시간 |

추가 예고 공격도 기존 적 공격 예산을 공유한다. 일반 적 예고 최대 3개, 초반 2개, 생성 간격 최소 0.8초와 피해 회복 간격을 우회하지 않는다. 누출·분출·방전은 `EnemyAttack`으로 집계되며 지형 피해에 합산하지 않는다. 절단은 기존 레이저 피해 범주로 묶되 표시를 `절단·레이저`로 명확히 했다. 동일 조건 실력전과 주간 도전에는 지역 공격을 적용하지 않는다.

역할별 회수 누적량·조립 비용·유료 상품은 변경하지 않았다. 소환기가 생산하는 적 역할이 달라지므로 실제 부품 종류별 획득 비중은 달라질 수 있다. 포격/자폭 → 포신, 추격/돌진 → 구동부, 방패/소환 → 장갑의 기존 회수 누적 규칙을 사용한다. 부족한 부품을 공급하는 운반 적은 기존 포/동/장 표식으로 구분한다. 모든 처치가 즉시 부품 하나를 떨어뜨린다고 표시하지 않는다.

작전 정보의 **지역 몬스터 · 공략과 회수 부품**에서 실제 출현 가능한 편성의 그림·이름·부품을 볼 수 있다. 기체 조립의 수집 목표 안내도 근처 지역 몬스터 이름을 사용한다. 전투에 이름표를 상시 추가하지 않았고, 플레이어·위험 예고의 표시 우선순위를 유지한다. 냉각 방패의 방어 방향과 돌진 준비 방향만 짧은 선으로 표시한다.

## 이미지와 생성 기록

내장 `image_gen` 도구로 생성한 투명 PNG를 변형 없이 프로젝트에 복사했다.

- [지역 1~5 이미지](../Assets/Resources/Art/RegionalEnemies-A-v1.png), [프롬프트](../ArtSource/RegionalEnemies-A-v1.prompt.txt)
- [지역 6~10 이미지](../Assets/Resources/Art/RegionalEnemies-B-v1.png), [프롬프트](../ArtSource/RegionalEnemies-B-v1.prompt.txt)

각 이미지 6열 × 5행이다. 두 번째 이미지의 실제 행 간격에 맞춰 런타임 Sprite 영역을 지정해 다음 행의 안테나가 섞이는 문제를 수정했다. Android는 최대 1024px ETC2 RGBA8로 가져온다. 런타임은 지역·역할별 Sprite를 캐시하여 적마다 매 프레임 아틀라스 키 문자열을 생성하지 않는다. 적마다 기본 그림 1장이며, 이동 흔들림·준비 압축·공격 반동·피격 점멸은 런타임 변형이다. 새 4프레임 애니메이션 60세트를 제작한 것은 아니다.

## 검증 범위

- 코어 규칙 129개, Unity EditMode 169개, 서버 검사 402개 통과. 지역 행동, 경고 수 제한, 방패 측면 공략, 실력전 격리, 10개 지역 재현과 이미지 매핑을 확인했다.
- 동일한 실제 획득 장비로 변경 전/후 각 60판: 10개 지역의 진입 작전 × 조작 2종 × 시드 3개. [입력](reports/region037-inputs.json.gz), [변경 전](reports/region037-before.json.gz), [변경 후](reports/region037-after.json.gz). 각 지역·조작의 승리 수 감소는 없었다. **표본이 작고 모든 작전을 검사한 것이 아니므로 전체 승률로 해석하면 안 된다.** 특히 폐철도 자연 조작의 피해 중앙값은 986 → 1,755로 증가했다. 자연 조작은 23/30 → 27/30, 회피 조작은 29/30 → 29/30이었다. 사람 난이도 합격이나 전체 경제 재검증은 아니다.
- Unity 실행에서 내보낸 지역별 전투 10개를 .NET으로 다시 돌려 처치 수·체력·결과가 허용 오차 내에서 일치했다. 크기·공격 범위·보상 검증을 느슨하게 하지 않았다.
- macOS 360×800 최종 화면 30개에서 오류 0건. [안내 화면](reports/runtime037/region-0-guide.png), [폐철도](reports/runtime037/region-1-family.png), [냉각 시설 밀집 장면](reports/runtime037/region-3-crowd.png), [송전탑 안내](reports/runtime037/region-8-guide.png). [압축 보관된 Unity 입력의 서버 재생 결과](reports/runtime037/replay-check.json)는 10/10 통과다.
- Android 실물 기기와 실행 중인 에뮬레이터는 연결되어 있지 않았다. 실기기 성능·발열·터치 및 사람 플레이는 미검증이다.

변경 전 비교 코어는 `3194f41`에서 별도 임시 폴더에 복원했고 같은 `RegionalAudit` 측정기와 입력을 사용했다. 입력 장비는 0.36 달력의 보석 보존 경로에서 실제 획득한 첫 진입 상태다. 예고와 공격을 단위 검사에서 강제 배치한 장면은 밸런스 표본에 포함하지 않는다.

## BM 검증 후 유지한 결정

[0.36 재검증 결과](reports/review036.md)는 지역 공격 변경 이전 자료다. 28일·80경로·8,864판 모두 60작전 완료, 무료 보석 보존과 의상 구매 경로의 진행이 일치했다. 자연 조작의 60작전 완료 중앙값은 보석 보존 18일, 무료 보석 보급 16일, 보급+패스 모의 충전 15일이었다. 같은 시드의 유료/보존 차이는 중앙값 3.5일이지만 일부 시드는 오히려 느렸으므로 보장하지 않는다.

18~24작전의 별도 70개 진입 프로필에서 보급 1회는 무기 약 2단계의 추가 성장과 무료 반복 약 8~10분 생략에 해당했다. 무료와 같은 목표 무기를 만들면 결과가 같았으며, 구매 후 같은 횟수 더 플레이하면 더 성장할 수 있었다. 무료 진행을 더 느리게 만들거나 무료/유료 보급량을 억지로 같게 맞추지 않았다.

장착 성장 상한 이후 보급 수요가 사라지는 한계는 남는다. 같은 대원의 성장 상품으로 무한 반복 매출이 발생한다고 주장하지 않으며, 실제 구매 만족도·광고 수익·다른 대원 성장 수요는 사람 검증 대상이다.

## APK 패키징

반복 Android 빌드에서 교체된 IL2CPP 라이브러리의 이전 ZIP 데이터가 산출물에 남아 약 18MB가 불필요하게 증가한 것을 확인했다. Gradle 산출 APK를 없애고 재패키징하면 같은 코드·리소스의 크기가 정상으로 돌아왔다. 이후 APK 빌드 직전에 생성된 Gradle APK만 무효화하도록 변경했다. 컴파일 캐시와 기존 배포용 산출물은 유지하며 AAB 경로에는 적용하지 않는다. 최종 파일은 서명·16KB ZIP/ELF 정렬·패키지·버전을 다시 검사한다.

최종 Android 체험 APK: `Builds/Android/ScrapGuard-playtest.apk`, 0.37.0/code40, 118417581 bytes (112.93 MiB). 0.36 체험 APK 대비 약 3.30 MiB 증가다. [패키징 검사](reports/apk037-playtest.json): QA 패키지·arm64·v2 서명·16KB ZIP/ELF 정렬 통과. 실제 기기에 설치·실행하지 않았다.
