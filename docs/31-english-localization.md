# 0.42.0 영어 지원

## 범위

- 로컬 버전 0.42.0 / Android 46. 전투 규칙 30 유지.
- 기본 설정은 기기 언어. 한국어 기기는 한국어, 나머지는 영어를 사용한다.
- 시작 화면 우측 위와 설정의 `Language / 언어`에서 기기 언어·한국어·English를 선택한다. 선택은 기기에 저장하며 화면 문구는 즉시 갱신한다.
- 홈, 강화, 장비, 대원, 로봇 도감·조립, 60개 작전/10개 지역, 실시간 전투 안내, 결과, 상점, 출석, 주간 도전, 길드·전시실, 계정·광고·복원 안내를 번역한다.
- Android 설치 이름은 기기 언어에 따라 한국어 `고철 수호대`, 기본 `Scrap Guard`다. 패키지 ID와 아이콘은 유지한다.

## 저장·구매·전투 보호

표시 계층에서만 번역한다. Core의 한국어 문자열은 기존 판정 및 기록과 함께 유지하며 상품 ID, 가격, 지급량, 전투 입력, 해시, 서버 계약을 바꾸지 않는다. 서버 응답의 기존 한국어 안내도 같은 카탈로그로 표시한다.

닉네임·길드 이름은 `Localization.Verbatim`으로 보호한다. 입력 필드의 실제 입력은 일반 `Text`를 사용한다. Google Play가 제공하는 지역별 실제 가격 문자열도 그대로 표시한다. 사용자 이름이 한국어로 보이는 것은 번역 누락이 아니다.

Google 구매창·광고 동의창·외부 웹페이지는 게임 UI와 별개다. 후속 배포 작업에서 Play Console 상품 5종의 영어 번역을 저장했다. 외부 개인정보·계정 삭제 웹페이지의 영어화는 아직 별도 과제다.

## 번역 유지보수

- 카탈로그: `Assets/Resources/Localization/en.json`. 키는 기존 한국어 원문, 값은 영어다. 런타임 외부 번역 API를 사용하지 않는다.
- 완전 일치 문구를 먼저 사용하고, 숫자·이름이 결합된 문장은 원문 구문들을 조합한다. 겹치는 짧은 구문이 긴 용어의 일부를 가로채지 않도록 전체 한국어 포함 범위와 구문 길이를 비교한다. 최대 4,096개 조합을 캐시한다.
- `LocalizedText`가 `.text` 갱신과 언어 전환을 처리한다. 프레임마다 전체 UI를 순회하지 않는다.
- 영어는 각 문구 영역 안에서 글자 크기를 조절한다. 새 문구는 실제 화면에서 잘림을 함께 확인한다.
- 새 한국어 UI/서버 안내를 추가하면 카탈로그도 갱신하고 `python3 Tools/check_localization.py`를 실행한다. 정적 리터럴 검사는 조합된 문장의 품질 검사를 대신하지 않는다.
- `Outfits.HeroName`의 분리된 이름, 의상 설명의 줄바꿈처럼 런타임에서 변환하는 문구도 번역과 테스트에 포함한다.

## 검증 절차

1. `python3 Tools/check_localization.py`
2. Unity EditMode: `LocalizationTests`와 기존 테스트. 기기 언어 선택, 사용자 이름/가격 보존, 실제 입력 보존, 저장 변경 없음, 숫자 조합·구문 충돌, 대원/지역/로봇/상품 번역을 확인한다.
3. `ProjectBuilder.BuildAndroidLocalizationQA`: 격리 패키지 `.qa`, 새 로컬 프로필, 온라인 저장·구매 없이 실행한다.
4. QA는 제목·언어 선택·홈·성장·상점 3탭·5개 상품·계정·설정·10지역 지도·기체별 도감·조립·레벨업·전투·결과 화면을 캡처한다. 한국어 잔존, 버튼 가림, 영어 텍스트 높이를 검사하고 `report.txt`, `texts.txt`를 남긴다.

macOS 최초 실행에서 조합 문자열의 번역 충돌과 제목 줄바꿈을 발견해 수정했다. Android 후속 검사에서 발견한 잘림 5건(문구 4종)도 줄였다. 최종 결과: 카탈로그 2,465개 누락 검사 통과, Unity EditMode **186/186**, Android API 35·ARM64에서 **50개 화면 검사 오류 0건**. 시작 화면에서 실제 언어 버튼을 클릭해 저장 값 변경을 확인했다.

최종 검증 결과와 대표 캡처는 [english042](reports/english042/README.md)에 보관한다. 실제 Google 결제·광고를 다시 수행한 결과나 실물 폰 성능 결과로 해석하지 않는다.

## 배포와 해외 출시

영어 스토어 소개문과 상품명 번역은 `Store/en-US`에 둔다. 2026-11-25 후속 배포에서 버전·영어 소개의 Google 검토 요청과 상품 번역 저장을 진행했다. 국가 타기팅·상품 가격은 유지했다.

기존 업로드 키로 서명한 `Builds/Android/ScrapGuard-0.42.0-46.aab`를 준비했고 bundletool 구조 검사·서명 검사·버전과 언어별 설치 이름 검사를 통과했다. **Play 업로드와 Google 검토 요청을 완료했다. 승인·실제 공개는 아직 확인하지 않았다.** [배포 기록](32-release-042.md).

Play에 영어판을 올리고 해외 국가를 열기 전에는 영어 스크린샷·상품 번역·개인정보처리방침·계정 삭제 안내, 대상 국가의 판매 가능 여부와 광고 동의 흐름을 확인한다. 기기 언어 자동 선택만으로 국가별 운영 준비가 끝났다고 판단하지 않는다.
