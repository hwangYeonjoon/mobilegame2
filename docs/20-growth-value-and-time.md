# 0.36 성장 보급의 추가 효과와 시간 가치

개발본 0.36.0 / Android code 39 / 전투 규칙 26. 서버·Play 배포 없음. 성장 판매를 유지하면서 구매가 만들어 내는 추가 효과와 즉시 사용 경험을 분리해 확인한다.

## 구매 경험

현재 보유 재료로 가능한 최대 강화와 보급을 더했을 때 가능한 최대 강화를 같은 경로에서 비교한다. 예를 들어 현재 Lv.2, 보유 재료로 Lv.4, 구매 후 Lv.7이면 전체 강화는 5단계지만 **구매의 추가 효과는 3단계**다. 공격·체력·모듈 실제 효과, 기존 재료까지 합친 소비량, 남는 재료와 보석을 확인하고 실행한다. 다른 경로가 동시에 강화된다고 표시하지 않는다.

구매 후 재료만 받는 화면을 거치지 않고 선택한 경로에 적용한다. 결과에는 실제 전후 능력치와 현재 작전 출격 버튼을 표시한다. 일반 작전 패배 화면에서 왔다면 해당 작전으로 돌아간다. 구매와 강화는 `growth_kit_upgrade` 한 명령으로 서버가 사전 검증하고 정산하며, 요청 재전송·진행 revision·대원·장비 ID·시작 레벨·강화 수·해금·하루 제한·환불 부채를 검사한다. 기존 단독 `buy` 명령과 이미 지급한 재료는 보존한다.

## 공개 구성

| 구간 | 상품 ID | 골드·부품 | 가격 |
|---|---|---|---|
| 처음부터 | growth_kit | 4,500 · 40 | 100보석 |
| 12작전 완료 | growth_kit_field | 9,000 · 80 | 100보석 |
| 30작전 완료 | growth_kit_frontier | 15,000 · 120 | 100보석 |

전체 합쳐 하루 1회다. 동일 상품의 구성은 고정이며 계정별 가격은 없다. UI는 열린 가장 큰 상품을 안내한다. 구버전 요청의 `growth_kit`은 기존 구성을 그대로 지급한다. 무료 현장 보급은 하루 전투 합산 300초(각 전투 최소 60초), 4,500골드·40부품으로 유지한다. 무료 성장을 늦추거나 상한을 늘리지 않았다. 동일 조건 실력전 능력치도 그대로다.

추가 강화가 없는 경로는 구매를 막고 보유 재료 사용을 안내한다. 모든 장착 대상에 추가 효과가 없으면 기존 단독 구매 명령도 거절한다. 상한 미달이어도 이미 가진 재료가 모든 강화를 충당하면 판매하지 않는다. 이는 미래 재료 비축 상품이 아니라 즉시 성장에 사용하는 보급이라는 범위다.

Lv.16 장비·잔액 0의 기능 검증에서 기본 보급은 다음 강화 4,800골드를 충당하지 못하고 심부 보급은 Lv.18까지 2단계를 충당한다. 이 사례는 상품 계산 검사이며 실제 후반 이용자의 평균 상태를 뜻하지 않는다.

## 시간 가치 비교

[결과](reports/growth036-value.md), [원본](reports/growth036-value.json.gz), [입력](reports/growth036-inputs.json).

0.33 보석 보존 경로에서 실제로 획득했던 7·13·31작전 진입 장비를 사용했다. 조작 2종 × 시드 10개 × 작전 3개 × 경로 4개 = 240경로, 총 465판이다. 보유 재료로 목표 무기를 강화하는 무료 경로, 외형만 구매하는 경로, 보급 구매로 반복을 생략하는 경로, 구매 후 무료와 같은 횟수만큼 더 플레이하는 경로를 비교했다. 실제 현금 결제는 없다.

7·13작전은 구매로 무기 1~2단계가 추가되고, 무료로 같은 목표 레벨을 만들기 위한 반복 시간을 중앙값 약 7~10분 생략했다. 시간은 전투 모의 시간에 판당 메뉴 30초를 더한 가정이다. 모든 해당 표본이 무료로도 목표에 도달했다. 구매 후 같은 횟수만큼 더 플레이한 경로의 진입 공격력은 더 높았지만, 이 표본은 목표 작전을 무료도 모두 이겼으므로 구매가 막힌 구간을 해결했다는 증거는 아니다.

31작전 표본은 무기가 상한이라 구매 효과가 없었다. 새 심부 보급이 대체 장비·대원 성장에 실제로 팔릴지는 검증하지 않았다. 전 경로의 무료/외형 선택은 같은 목표 도달 시간과 전투 결과였다. 600보석이 부족한 경우 외형 구매를 생략했으므로 전원이 구매했다는 뜻은 아니다.

무료 경로를 최대 6회 반복으로 제한했고, 미달 목표는 시간 절약 통계에서 제외한다. 같은 날 무료 현장 보급 미수령 상태로 시작한다. 출석·임무·광고·패스·다른 슬롯 강화·장비 교체·전체 캠페인 진행은 제외했다. 실제 사람에게는 반복 대신 진행하다 자연스럽게 보상을 받는 선택도 있다. 따라서 **게임 화면에 절약 시간이나 보장 승률을 표시하지 않는다.** 기존 구매 측정기는 새 고정 구성을 사용하고 추가 강화가 없으면 구입을 중단하도록 갱신했다. 과거 보관 결과는 당시 버전의 기록으로 유지한다.

## 검증과 남은 작업

코어 127개, Unity EditMode 166개, 서버 402개 통과. 새 검사는 구간별 해금·동일 하루 한도·구매 추가 효과·상한과 충분한 기존 재료·잘못된 강화 요청·동시 구매/강화 정산·서버 재요청·서버 재시작·환불 부채를 포함한다. 구매 측정 도구 검사 20개도 통과했다. 직접 조작용 Android 체험 APK는 0.36.0/code39 빌드·서명·arm64·16KB ZIP/ELF 정렬 검사를 통과했다([검사 결과](reports/apk036-playtest.json)). 실물 Android 설치·실행은 이번에도 미실시다. 이전 에뮬레이터 시스템 UI 오류를 해결했다고 주장하지 않는다. 최종 macOS 빌드 UI 60화면 오류 0개와 전투 기록 15개의 .NET 재생 일치를 확인했다. 구매·강화 후 출격한 전투의 공격력이 실제 장착 능력치와 일치하는지도 자동 검사했다. [구매 비교](reports/runtime036/04-kit-preview.png), [확정 전 비용](reports/runtime036/04b-kit-confirm.png), [강화 결과](reports/runtime036/05-kit-use-now.png), [공개 구성](reports/runtime036/43-kit-public-catalog.png). UI fixture는 테스트용 재화·해금을 사용하며 경제 측정과 분리했다. 처음 검사에서 기존 외형 테스트가 구매 후 높아진 무기 레벨에 비해 부족한 고정 재료를 넣어 실패했고, 해당 fixture를 독립된 Lv.1 무기로 고친 뒤 전체 화면 검사를 다시 통과했다.

사람의 구매 만족도, 전체 60작전의 반복 구매 효과와 장기 재화 누적, 대체 성장 대상 수요는 미검증이다. 새로운 성장 상한·대원·무기·유료 전용 능력은 추가하지 않았다. Android 실물 기기 검증도 별도로 필요하다. 운영 서버와 Play 트랙에 배포하지 않는다.

## 2026-11-11 추가 확인

새 구성으로 진행한 28일 달력과 누락됐던 18~24작전 시간 가치를 [별도 보고서](reports/review036.md)에 보존했다. 0.36 전투 규칙 26 기준이며 0.37 지역 몬스터 변경 후의 전체 난이도 자료가 아니다. 성장 판매와 무료 현장 보급은 유지한다.
