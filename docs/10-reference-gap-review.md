# 유명 게임 비교와 고철 수호대의 부족한 점

## 2026-11-05 조사 후 UI·이미지 보강 반영 (로컬)

아래 b44a462 감사에서 제안한 장비 12종/스킬 8종 그림, 공통 등급 표시, 반응형 메뉴, 카드 전체 선택, 의상 썸네일과 필터, 현재 장비 대비 구매 비교, 보석 상품별 그림, 정비소/전시실 배경과 정보 위계, 전투 실루엣/외곽선/그림자, 맵 명암·환경 효과를 구현했다. 상세 범위와 생성 원본은 `docs/06-art-combat-and-operations.md`의 2026-11-05 절을 따른다.

전투 스킬 선택은 효과·다음 레벨·조합 진행을 분리하고 HUD/도감과 같은 그림을 쓴다. 전시 공유는 스크롤 마스크 밖에 카드 사본을 만들어 전체를 캡처한다. 다른 플레이어의 전시 장비·성장 기록도 상세 화면에서 확인한다. 장비 수치 비교는 현재 대원 레벨과 실제 코어 계산을 사용하며 기존 가격·수량·상품 ID·전투 판정을 변경하지 않는다.

Play 비공개 테스트 앱과 운영 서버는 업데이트하지 않았다. Android 서명 AAB도 이번 변경 이후 재생성하지 않았다. 연속 애니메이션 새 원화, Android 실기기 터치/장시간 성능, 실제 사용자 선호와 BM 전환 효과는 별도 검증·제작 범위다.


검증: Unity macOS 개발 빌드 성공. `TestResults/UiCompleteTall`(360×800), `TestResults/UiCompleteShort`(360×640) 각각 PNG 35개, 런타임/클릭 검사 오류 0건. 신규 그림 로드, 메뉴 안전 영역, 고정 출격 버튼, 구매 비교의 상태 불변, 장비 구매 차감, 의상 필터/빈 상태, 체험의 상태 불변, 의상 구매→장착→전시, 보석 부족 구매 차단, 스크롤 후 전체 카드 공유, 스킬 선택/도감/HUD, 7개 지역 표현을 확인했다. 전투·재화는 격리된 로컬 테스트 조건이며 실결제/운영 서버 검증이 아니다. `BattlePresentationSpecification` 4개 통과(`TestResults/ui-battle-presentation.xml`): 전체 42작전 충돌 경계 일치, 파티클 수명/상한, 적 오브젝트 재사용 상태, 특수 던전 바닥/장애물 분리. Android 실기기 검증을 대체하지 않는다.

## 2026-11-05 UI·이미지 재점검 — b44a462 기준

범위: 최신 `TestResults/ShopPolish` 360×800 미리보기 캡처와 현재 UI 소스, 아래 개발사 Google Play 등록 이미지. 경쟁작 이미지는 홍보용 합성이 포함돼 있으므로 실제 모든 메뉴·터치 동선을 직접 검증했다고 보지 않는다. 현재 게임의 위험 배치·전투 결과 캡처도 UI 검증용 합성 조건이다. 이번 작업은 조사이며 게임 구현·운영 배포는 변경하지 않았다.

### 비교 근거

- [탕탕특공대 공식 Google Play](https://play.google.com/store/apps/details?id=com.dxx.firenow&hl=ko): 스킬 선택·진화 소개 이미지에서 큰 도형 아이콘, 굵은 외곽선, 선택 상태와 단계 표시가 함께 보인다. 구체적인 UI 동선을 그대로 이식하기보다 작은 크기에서도 알아보는 아이콘과 단계 표현을 참고한다.
- [궁수의 전설2 공식 Google Play](https://play.google.com/store/apps/details?id=com.xq.archeroii&hl=ko): 장비 소개 이미지에 개별 장비 그림·등급 프레임·슬롯 기호·탭을 함께 사용한다. 스킬 소개는 그림, 이름, 효과, 희귀도를 구분한다. 캐릭터 소개는 큰 실루엣·진열대·배경 조명으로 수집 대상을 강조한다.
- [Vampire Survivors 공식 Google Play](https://play.google.com/store/apps/details?id=com.poncle.vampiresurvivors&hl=ko): 전투 소개 이미지에서 적·경험치·발사체·배경이 일관된 픽셀 스타일로 표현된다. 고밀도 전투를 항상 읽기 쉽다고 단정하지 않으며, 아트 스타일 통일과 지형/행위 요소 구분을 참고한다.
- [Android 접근성 안내](https://developer.android.com/guide/topics/ui/accessibility/apps): 터치 대상 최소 48×48dp 권장, 작은 글씨 대비 4.5:1 권장. Unity 논리 좌표·미리보기 픽셀은 Android dp와 같지 않으므로 실제 기기에서 별도로 확인한다.

## 0.16 실제 서비스 연결 전 보완

일반/라이선스 결제 처리와 판매 중지·복원 분리, AdMob SDK·UMP와 SSV 서버 보상, 보상 내역·취소, 운영자 신고/보상/원장 조회, 장애·환불·백업 상태 점검을 추가했다. 기본 결제·광고는 꺼져 있고 외부 계정·공개 서버·실기기 거래는 아직 연결하지 않았다. 화면과 서버 모의 검증은 실제 Google 승인·광고 송출 증거가 아니다.

테스터 없이 할 수 있는 경제 계산은 `Tools/EconomyForecast`로 반복한다. 현재 출석+임무를 매일 완료하고 소비하지 않으면 13일에 600보석, 60일에 3,050보석이다. 첫 클리어·주간 보상도 제외한 시나리오이므로 의상 4종만으로 장기 수익성이 확보됐다고 판단하지 않는다. 다음 외형 공급, 실제 결제/광고 연결, 실기기 성능과 운영 배포가 후속이다.

## BM 판단

현재 보석은 캐릭터·장비·부품·외형에 사용하고, 현금 상품은 미연결이다. 콘텐츠 확장으로 무료 보석 공급이 늘었으므로 지금은 새 패키지를 늘리기보다 성장 속도와 반복 플레이를 먼저 측정한다.

다음 외형 상품은 단순 도색 외에 전용 필살기 표현·지원 등장 연출처럼 구매 전에 확인할 수 있는 묶음이 어울린다. 게임으로 획득하는 지역 트로피와 칭호도 함께 전시한다. 상품이 어려운 구간을 통과하는 유일한 수단이 되도록 난이도를 조정하지 않는다. 모든 기능을 한 번에 도입하기보다 한 판의 재미와 명확한 다음 목표를 먼저 완성한다.

## 검증할 지표

첫 실행→첫 전투→첫 강화→두 번째 출격, 작전별 성공/포기/사망 원인, 사용 조합과 보스 잔여 체력, 무료 보석 수입/소비, 지역별 재방문, 전시 열람→피팅→구매 전환을 구분한다. 현재 실제 이용자 데이터 수집은 구현되지 않았으므로 수치 목표나 효과를 달성했다고 볼 수 없다.
