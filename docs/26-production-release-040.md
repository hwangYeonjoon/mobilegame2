# 0.40.0 정식 출시·실결제 전환 (2026-11-23)

## 현재 배포 상태

- 최신 로컬 소스: **0.40.0 / Android versionCode 43 / 전투 규칙 30**. 로봇 테마 작전 등 0.40 변경을 포함한다.
- Play 내부 테스트: 11월 23일 10:37 KST **게시 완료**. 스토어 반영에는 시간이 걸릴 수 있다.
- 프로덕션: 제출 당시 Google 검토 중이었으며, 이후 11월 23일 Console에서 **게시 완료·100% 제공·게시되지 않은 변경사항 없음**을 확인했다. 비공개 테스트 Alpha 업데이트도 함께 제출했으며, 아래 검증 기록은 제출 시점 결과를 포함한다. 관리형 게시는 사용 중지 상태다.
- 운영 서버: `scrapguard-api:0.40.0` 전환 완료. `/v1/release` latest/minimum 43, 규칙30, playAvailable=true.
- 구버전 21은 서버 규칙이 달라 업데이트가 필요하다. 내부 테스트와 정식 프로덕션에 새 버전 제공 경로를 확보했다. 기기별 Play 반영과 업데이트는 별도 확인 대상이다. 기존 계정과 구매 기록을 삭제하거나 초기화하지 않았다.

## 실결제와 광고

- 사용자 요청에 따라 운영을 `COMMERCE_MODE=production`, `COMMERCE_RELEASE_READY=true`, 신규 판매 활성으로 전환했다.
- 현재 실판매 상품은 **보석 300개 / gems_300 / 대한민국 2,200원**이다. Play 구매 옵션 `standard` 활성 및 이전 버전 호환을 확인했다.
- gems_600, gems_1200, gems_2600, ad_skip_lifetime은 준비되지 않은 상품이므로 서버 판매 목록에서 제외했다.
- 새 검증 계정의 `/v1/commerce` 응답에서 enabled=true, salesEnabled=true, licenseTest=false, saleProducts=[gems_300] 확인.
- RTDN은 유지했고, 환불 조회/장기 누락 복구 상태 정상, 오류·미처리 0건이다. 별도 빈 DB에서 실제 Google 환불 API 조회도 성공했다.
- **실제 카드 청구 구매는 수행하지 않았다.** 설정 활성화와 실제 결제·지급·환불의 종단 검증을 구분한다. Google 라이선스 테스트 결제와 테스트 진행 계정은 운영 실결제로 처리하지 않는 정책을 유지한다. 기존 테스트 구매 계정은 실결제가 제한된다.
- AdMob 고철 수호대는 아직 스토어 미연결·검토 필요·광고 게재 제한 상태다. 클라이언트는 실제 광고 ID로 준비했지만, 운영 서버는 **ADS_MODE=disabled**다. 공개 후 스토어 연결·AdMob 승인 확인을 거쳐 별도로 전환해야 한다.
- AdMob 보상형 SSV URL은 `https://api.scrapguard.win/v1/ads/ssv`로 이미 연결되어 있다.

- `Builds/Android/ScrapGuard-production.aab` SHA-256: `2bd8b104da791dd88cc065e2bde5c325f5dcbd44751a3f45e5d0cb814ed8b736`. Google 업로드본 해시와 일치한다.

- QA 에뮬레이터 저장 공간 부족은 이전 QA 결과 448개를 보관한 뒤 QA 전용 패키지만 제거해 해결했다. 사용자 로그인 Play AVD는 건드리지 않았다.
- 정식 APK 설치·실행 성공. 전환 전 구서버 불일치 안내와 전환 후 정상 타이틀 화면을 확인했다. 실행 로그의 Unity/AndroidRuntime 오류 출력은 없었다. 이번 정식 빌드로 실기기 성능이나 실제 청구 구매를 검증한 것은 아니다.
- 운영 전용 검증 계정으로 초대코드 없는 가입, 재접속, 저장, 동일 요청 재시도 중복 처리 방지, 실판매 상품 목록, 광고 비활성을 확인했다. 기존 사용자 상태나 재화를 수정하지 않았다.
- 원본 로그: `TestResults/release040-*`. 비밀정보 없는 핵심 결과는 [검증 기록](reports/release040/README.md)에 보관한다.

## 운영 데이터 보호

- 전환 전 DB·구매 토큰 암호화 키 백업: `/backups/scrapguard-pre040-20261123.db` 및 `/backups/scrapguard-cutover040-20261123.db`, 각각 `.keys` 포함. 백업 무결성 검증 통과.
- 백업 복사본을 새 서버에서 마이그레이션한 뒤 계정 2개, 진행 중 작전 1개, 구매 1개, 환불 1개를 확인했다. 운영 검증 계정은 이후 별도로 추가됐다.
- 이전 환경은 운영 서버의 `.env.pre040-20261123`에 비공개로 보관했다. 로컬 비공개 배포 환경도 현재 운영 설정과 일치시켰다.
- 진행 중 구규칙 작전은 자동 삭제하지 않았다. 새 앱 계정 화면의 ‘중단된 작전 종료 (보상 없음)’로 정리할 수 있다.
- 구버전/신버전 서버를 같은 DB에 동시에 연결하지 않았다. 별도 마이그레이션·실결제 검증 컨테이너는 중지했다.

## 빌드와 Console 참고

- `python3 Tools/build_signed_aab.py --production`: HTTPS 운영 연결, 패키지명, 공개 지원 URL, 실제 광고 설정을 검사하고 기존 업로드 키로 서명한다. 비밀번호는 인수/로그에 남기지 않는다.
- Play 경고: Java 가독화 파일과 네이티브 디버그 기호가 미첨부되어 있다. 심사 차단은 아니지만 향후 장애 분석 보강이 필요하다.
- 세로 화면 하드웨어 필수 선언에 대해서는 현재 세로형 Android 게임 대상으로 출시한다는 사유를 제출했다. 가로 전용/다른 폼팩터 지원은 별도 레이아웃 검증 대상이다.
- Chrome 연결이 잠시 끊겼으나 복구 후 Console에서 최종 제출했다. 서비스 계정 API는 조회/트랙 초안 수정은 가능하지만 edits.validate는 403이었다. API 초안은 commit하지 않았다. 불필요한 권한 확대는 하지 않았다.

## 남은 확인

3. 공개 스토어와 AdMob 연결, 광고 심사 상태 확인 후 운영 광고 활성화.
