## 비공개 서버 대시보드

```sh
cd /Users/kd-server/IdeaProjects/mobilegame2
python3 -m Tools.launch_dashboard
open UserSettings/Operations/index.html
```

Finder에서 `Tools/open_operations_dashboard.command`를 실행해도 된다. 기존 Lightsail SSH 키와 known_hosts가 필요하다. 별도 호스팅·유료 분석 도구·앱 업데이트가 필요 없다. 갱신은 위 명령 실행 시에만 이루어진다. HTML을 새로고침하는 것만으로 서버를 조회하지 않는다. 자동 스케줄은 등록하지 않았다.

- 서버에서 SQLite `mode=ro`, `query_only`, 단일 읽기 트랜잭션으로 집계한다. 운영 DB를 수정하지 않고 원본 계정·복구 코드·영수증을 내려받지 않는다.
- 결과는 git에서 제외되는 `UserSettings/Operations`에 보관한다. 파일 권한 0600, 새 출력 디렉터리 0700. 외부 공개 URL이 아니다.
- 테스트 진행 계정, 로컬 심사 계정과 출시 QA 계정을 제외한다. 추가 검증 계정은 비공개 `UserSettings/Secrets/operations-exclusions.json`에 `{"ids":["계정 ID"]}`로 지정한다. 현금 결제와 테스트 결제의 미확인 유형은 실결제 합계에 포함하지 않는다.
- 서버 신규 계정 / 성공한 명령의 일별 활동, UTC 가입 코호트 D1·D7, 실제 구매 검증·환불 상태, 최고 해금 작전 분포, 보석 원장, 광고 보상, 서비스·환불 복구 상태를 표시한다.
- **서버 활동은 앱 실행 DAU가 아니다.** 오프라인 이용자는 포함되지 않는다. 삭제 계정의 기록도 사라진다. D1/D7은 가입 다음 1/7일째 UTC 하루가 완전히 끝나야 계산한다. 표본 수와 관찰 중을 함께 표시한다.
- 활동 보관은 90일이다. `--since YYYY-MM-DD`로 기간을 지정할 수 있으며 오래된 원장이 남아 있더라도 활동이 삭제된 기간의 유지율을 계산하지 않도록 최근 83일 이내만 허용한다. 기본값은 출시일 이후의 최근 28일이다.
- 구매 수는 서버에서 검증된 영수증 수이고 원화 매출이 아니다. 환불 수는 기간 내 구매의 **현재** 취소 상태이며 환불 발생일 통계가 아니다. 광고 제거 권리 지급과 SSV 광고 보상은 별도로 집계한다. 광고 요청·보상 기록은 노출 수와 같지 않다.
- 계정 진행 분포는 현재 스냅샷이며 작전별 이탈률이 아니다. 현재 기록만으로 이탈 시점·튜토리얼 전체 완료·게임 세션 길이를 만들어내지 않는다.
