# 0.34 로봇 구매 가치와 캠페인 확장

개발본 0.34.0 / Android code 37 / 전투 규칙 25. 운영 서버·Google Play에는 배포하지 않았다. 실제 결제·광고 호출 없이 격리된 QA 계정과 재화로 검증한다.

## 구현

### 60작전, 10지역

기존 1~42작전의 ID·첫 완료 보상·완료 기록을 유지한다. 기존 마지막 작전을 완료한 계정은 새 규칙에서 43작전을 연다. 각 지역은 6작전이며 생존/보스 목표를 섞는다. 새 작전도 첫 완료 보석 50개와 확정 장비, 반복 시 골드·부품을 제공한다.

| 작전 | 지역 / 보스 | 지형 / 보스 행동 |
|---|---|---|
| 43~48 | 자력 선별장 / 자력 집게왕 | 자력 레일 좌우 이동 · 양옆 압착 뒤 지정 위치 타격 |
| 49~54 | 폭풍 송전탑 / 폭풍 지휘자 | 바람 통로 이동 · 빈 세로 통로를 남기는 시간차 낙뢰 |
| 55~60 | 궤도 조립항 / 궤도 조립모함 | 발사 레일 예고 · 두 번에 나눠 지나가는 가로/세로 발사 |

예고는 서버와 앱의 동일 코어에서 계산한다. 새 보스는 기존 공격 조율·울타리·예고 수 제한을 사용하고 별도의 지역 공격을 보스전 안에 중첩하지 않는다. 3종 모두 전용 4자세 아트를 사용한다. 지도·지역 수집은 지역 수가 늘어도 좁은 숫자 버튼이 되지 않도록 이전/다음 탐색으로 바꿨다. 새 지역 도색·수집·도감·보스 연습도 열린다.

바닥 연속 텍스처와 일부 시설물 원화는 기존 아트를 공유한다. 지역별 지형 배치·색·표식·흐름·보스는 다르지만, 18작전 전체가 서로 다른 게임 규칙이라는 뜻은 아니다. 한 번의 확장으로 수개월 콘텐츠가 확보됐다고 판단하지 않는다.

### 구매한 로봇이 바로 보이고, 성장을 바로 선택

- 성운 기사: 포격 전차·돌파 보행기·철벽 수호기의 실루엣이 다른 외형 3종, 골드 18,000, 부품 180. 계정당 1회 900보석. 구매 확인 버튼에 즉시 외형 적용을 명시한다.
- 기체·설계 미리보기, 전투, 조립실, 공개 프로필이 같은 소유 외형을 사용한다. 합체 등장 링·공격 입자·탄환 강조색도 연결한다. 외형 자체에는 능력치가 없다.
- 구매 뒤 집중 강화 화면을 연다. 현재 보유 재료를 합쳐 무기/방어구/모듈/대원 중 선택한 경로를 몇 단계 강화할 수 있는지, 정확한 비용과 전후 효과를 표시한다. 확인 후 해당 경로만 한 번에 강화한다.
- 서버가 장비 ID·시작 레벨·요청 단계·전체 비용을 다시 검사한다. 실패하면 부분 차감하지 않는다. 네 경로는 대안이며 한꺼번에 모두 적용할 수 있다는 표시를 하지 않는다.
- 장착 장비와 대원이 모두 최대면 기존 성장 보급 구매를 막는다. 다른 대원·장비를 선택하면 다시 평가한다. 외형 팩은 외형 때문에 구매할 수 있지만 최대 레벨 경로에는 추가 강화 불가를 표시한다.
- 기존 보석 충전 SKU, 패스 권리, 환불 부채 회수, 요청 재시도 멱등성을 유지한다. 외형 팩의 보석 가격은 게임 내 고정 가격이며 원화 충전액은 Play 결제창의 현지 가격이 기준이다.

### 성장 완료 뒤 재료 사용

회수 선봉대는 3기체별 무료 제작 외형이다. 작전 42 완료 후 기체별 골드 30,000·부품 300·코어 파편 12개로 제작해 즉시 적용한다. 파편은 주간 도전에서 얻는다. 원형 실루엣·등짐·포신·장갑이 다른 원화이며 색만 바꾼 상품이 아니다. 3종 완성 이후 무한 재료 소비나 영구 반복 수요는 아직 제공하지 않는다.

### 일일 반복 숙제 완화

과거의 완료 작전 90초 이상 3승 조건을 폐지했다. 새 작전·재도전·주간 도전에서 60초 이상 진행한 전투 시간이 하루 총 300초가 되면 무료 골드 4,500·부품 40을 받는다. 승리·패배 모두 포함하고 메뉴·일시정지는 제외한다. 60초 이후 중단은 해당 실제 전투 시간만 반영한다. 연습과 고정 실력전은 보상에 포함하지 않는다.

기존 일일 회수 진행 1회당 100초를 한 번만 이관하고 이미 수령한 권리를 보존한다. 날짜 역행으로 보상이 다시 열리지 않는다. 실제 서버에서는 입력 재생 후 정산된 시간만 사용한다. 따라서 새 작전을 진행하며 무료 보급을 얻을 수 있으며 구매 경로도 이를 받기 위해 세 번씩 반복하지 않는다. 자동 접속 보상은 아니며 플레이 시간 조건은 남는다.

## 검증과 해석

- 공유 코어: 구매·중복·환불 부채·제작·집중 강화·일일 보급 이관·새 지역 이전 및 보스 입력 재생.
- 서버: 신규 팩의 검증된 보석 사용, 재시도, 재시작 후 소유권, 집중 강화, 환불 부채 처리.
- Unity: 60개 작전 충돌/표면, 보스 아트와 새 외형 시트, Unity JSON 필드 왕복.
- Android: 별도 QA 패키지와 수동 체험 APK. 물리 폰·사람 관찰은 수행하지 않았다.

공유 코어 123/123, Unity EditMode **162/162**, 서버 **383개** 통과. 달력 요약 검사는 12개 통과했다. APK 두 종류는 0.34.0/code 37, ARM64, API 26~36, 서명·16KB 정렬 검사 통과. QA 약 126.9MiB, 직접 조작용 체험 APK 약 109.6MiB다. QA와 수동 빌드의 용량을 서로 같은 것으로 취급하지 않는다.

[467판 원본 요약](reports/content034-audit.md): 각 조작 10시드에서 43~60작전 연속 진행을 모두 완료했다. 회피 봇 중앙값 18출격/80.2분, 자연 조작 봇 23.5출격/102.6분이다. 매 판 메뉴 시간 30초를 포함하며 사람의 분량을 보장하지 않는다.

팩 구매 뒤 무기 집중 강화 사례의 공격 수치는 중앙값 23.2%/27.9% 증가했다. **기존 재료도 사용했으며 무료 최적 강화와의 대조가 아니다.** 자연 조작의 같은 작전 승리는 전후 9/10으로 같고, 승리→패배 1개와 패배→승리 1개가 서로 교환됐다. 더 높은 공격력이 모든 봇 경로의 승리를 보장한다고 해석하지 않는다. 이것은 실제 강화 수치·전투 적용 확인이며 돈 쓴 체감의 사람 검증을 대신하지 않는다.

### 화면 실행과 남은 Android 제한

macOS 540×960 격리 로컬 프로필에서 **46개 화면, UI 오류 0개**를 확인했다. 새 보스 6개 작전, 기존 연습 3개, 주간 3개의 Unity 입력을 .NET에서 다시 실행해 **12/12 일치**했다. 이것은 Android 실행 증거가 아니다.

화면 검사에서 이웃 원화의 작은 조각이 섞이는 현상을 찾아 기체별 스프라이트 읽기 영역을 수정했다. QA의 연습 공격력 비교는 부동소수점 완전 일치 대신 0.001 이내와 스킬 레벨을 함께 확인한다. 전투 계산이나 서버 재생 검증 허용치는 변경하지 않았다.

Android QA AVD(API 35, 540×960)는 SwiftShader와 host GPU 모두 System UI 응답 오류가 발생했고, 첫 시도에는 앱 응답 오류도 있었다. 빌드·서명 검사만 통과한 상태이며 **Android 전투 실행은 미완료**다. [실패 기록](reports/runtime034/android-execution.json)을 보존했다. 물리 기기의 프레임·발열·터치감과 사람의 구매 만족감은 검증하지 않았다. 운영용 로그인 AVD의 계정은 초기화하지 않았다.

첫 macOS 시도는 기존 프로필의 서버 버전 안내에 막혀 중단했고, 새 로컬 프로필로 분리한 뒤 위 검증을 수행했다. 운영 서버를 새 버전으로 변경하지 않았다.

## 재현

```sh
dotnet run --project Tools/CoreChecks
dotnet run --project Server/Checks
python3 Tools/test_long_audit.py
python3 Tools/verify_runtime_replays.py TestResults/mac034-final --output TestResults/mac034-final-replay.json
dotnet run --project Tools/CoreChecks -- --content034-audit docs/reports/expansion034-inputs.json TestResults/content034-audit.json
```

`expansion034-inputs.json`은 보존된 0.33 달력 원본의 보석 보존 경로에서 추출한 실제 획득 장비 스냅샷이다. 각 조작 조건 10시드의 3일차와 첫 42완료일 종료 시점을 사용한다. 다른 소유 장비·과거 수령 기록 전체를 복원하는 도구는 아니므로 신규 계정의 60작전 전체 경제 예측으로 해석하지 않는다.

구매 비교는 3일차 스냅샷에 명시적 테스트 보석 900개를 넣고 팩 구매 → 무기 집중 강화를 수행한다. 비교 전 경로는 재료를 쓰지 않는다. 따라서 이것은 화면에서 약속한 구매 후 행동의 효과 검사이며, 무료 경로도 최적으로 강화한 대조 실험이나 현금의 순수 효과가 아니다. 로봇 외형의 실제 매력·돈 쓴 만족감은 사람 관찰로 확인해야 한다.

43~60 확장은 기존 첫 42완료일의 실제 장착 장비에서 이어가며, 하루 6출격·작전당 최대 6시도·실제 보상과 균형 강화·무료 현장 보급을 사용한다. 광고·보석 구매·강제 반복 보급은 없다. 과거 0.33 결과는 당시의 규칙으로 보존하고 새 결과와 섞지 않는다.

달력 도구는 schema 2부터 현재 캠페인 수와 `firstCampaignDay`를 기록하며 `first42Day`는 비교용 중간 체크포인트로 남긴다. 요약 도구는 두 버전의 보급 조건을 구분하고 최종 캠페인 완료를 별도로 검증한다.
